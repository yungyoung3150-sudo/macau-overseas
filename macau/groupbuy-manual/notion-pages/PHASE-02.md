## STEP-03 · 시딩 항공·호텔 가능 확인 → 바우처 전달

**목적** KOL 시딩 가능 일정을 채널별 담당자에게 전달해 항공·호텔 가능 여부를 확인하고, 받은 바우처를 검증해 KOL에게 전달한다.

**담당**
- 메인: 김용성, 정민님
- 리스보아 특전 구성: 리스보아 담당 이사님

**절차**
1. **KOL 정보 정리** — 채널 링크, 팔로워 수, 인원, 숙박 기간, 항공 필요 여부 (전 단계에서 정리한 자료 재확인)
2. **채널별 시딩 일정 전달** (항공·호텔 가능 여부 확인 요청)
	- 에어마카오 → 에어마카오 담당자 톡방에 전달
	- 에어부산 → 에어부산 단톡방에 전달
	- 갤럭시 → 갤럭시 담당자님에게 전달
	- 리스보아 → 리스보아 담당 이사님에게 전달
3. **가능 여부 회신 확인** — 좌석·요일·박수 규칙(출발 요일별 귀국일) 점검. 정확한 편명·스케줄·박수 규칙은 사내 마카오 항공 스케줄 자료를 기준으로 본다.
4. **바우처 수령**
	- 에어마카오·에어부산 항공 바우처 (에어마카오 담당자 톡방 / 에어부산 단톡방)
	- 갤럭시 호텔 바우처 (갤럭시 담당자님)
	- 리스보아 바우처 → **이사님 특전 구성 완료 후** 수령 (리스보아 담당 이사님)
5. **바우처 내용 검증** — 항목별로 일치 확인
	- 이름(여권 영문) / 날짜 / 항공 편명 · 호텔 객실 타입 / 인원
6. **KOL에게 바우처 전달** + 체크인/수속 안내
	- 리스보아 특전 → 이사님 확인 완료 후 KOL에게 추가 전달
7. 기본 상품 노션은 STEP-04에서 별도 전달 (수화물·호텔 구성·조식가·인펀트가·항공편·셔틀·포토스팟)

<callout icon="⚠️" color="red_bg">
	**주의** 리스보아 바우처는 이사님 확인 전 절대 먼저 보내지 말 것. 리스보아는 리스보아 담당 이사님이 호텔 특전을 직접 구성해주신다 → 이사님 확인 완료 전 KOL에게 먼저 발송 금지.
</callout>

<callout icon="⚠️" color="red_bg">
	**주의** 바우처 이름 = 여권 영문과 반드시 일치. 바우처 이름이 여권 영문과 다르면 발권·체크인이 거부될 수 있다. **여권 영문을 먼저 확보한 뒤 신청**하고, 수령한 바우처는 이름·날짜·편명·인원을 한 번 더 대조한다.
</callout>

<callout icon="⚙️" color="yellow_bg">
	**보완(확인필요)** 참조할 항공 스케줄 노트가 볼트에 들어오면 위키링크로 연결. 전달 전 인원 수·일정 반드시 재확인하고, 항공 스케줄은 변동될 수 있으므로 공구 전 반드시 재확인한다.
</callout>

**핵심 용어**: 시딩 — KOL에게 항공·호텔을 무료 제공해 홍보 유도 · 바우처 — 항공사·호텔에서 발행하는 이용권 · KOL — Key Opinion Leader, 공구 파트너 인플루언서 · 인펀트 — 만 2세 미만 유아, 별도 요금 체계

## STEP-04 · 기본 상품 노션 제공 & 촬영 구성 확인

**목적** 표준 마카오 상품 구성(기본 노션)을 KOL에게 먼저 보여주고, 이번 촬영에 어떤 구성·장면이 필요한지를 받아 답사 동선·상품 방향을 맞춘다.

**담당**
- 메인: 김용성, 정민님
- 리스보아 특전 구성: 리스보아 담당 이사님

**절차**
1. **기본 마카오 상품 구성 노션**을 KOL에게 공유 — 호텔 구성·항공편·수화물·옵션 풀·포토스팟이 정리된 핵심 자료

4. 정리한 요청 구성 메모를 STEP-06 제안·역제안 컨설팅의 입력값으로 넘김

## STEP-05 · 답사 전·중·후 인플 컨디션 체크

**목적** KOL이 마카오에서 촬영(답사)을 진행하고 귀국. KOL 주도이며 내 역할은 답사 전·중·후로 컨디션과 진행상황을 챙겨 촬영 차질과 관계 리스크를 막는 것.

**담당**
- 메인: KOL
- 서포트: 김용성 (답사 전·중·후 컨디션 체크 / 현지 요청 대응)

**절차**

**답사 전**
1. 일정·바우처·동선·연락 수단(현지 유심/로밍) 최종 확인.
2. KOL과 출발 전 연락 — 준비 상태·궁금증 점검.
3. STEP-04에서 KOL이 "콘텐츠에 담고 싶다"고 답한 촬영 구성 요청이 답사 동선에 반영됐는지 재확인.

**답사 중**
4. KOL 출발 (항공 바우처 사용).
5. 마카오 현지 촬영 진행.
6. 현지 이슈(체크인·일정 변동·돌발) 실시간 대응.
7. 추가 액티비티/경험 요청 시 → **가능 여부 먼저 확인 후** 대응(무조건 OK 금지).
8. 안부 체크 — 진행 상황·컨디션 확인.

**답사 후**
9. KOL 귀국 확인.
10. 촬영이 잘 됐는지·추가로 필요한 분량이 있는지 확인.
11. 감사 인사.
12. 귀국 후 STEP-06(제안·역제안 컨설팅)을 빠르게 진행.

<callout icon="⚠️" color="red_bg">
	**주의** 추가 요청 응대. KOL이 추가 액티비티/경험을 요청할 수 있음 → **무조건 OK 금지**, 가능 여부를 먼저 확인하고 대응. 귀국 후 STEP-06(역제안)을 **빠르게** 진행할 것. 지연 시 인플 피드 반응이 식어 구성 타이밍을 놓침.
</callout>

<callout icon="⚠️" color="red_bg">
	**주의** 응대 톤. 인플 응대는 **파트너 존중·팩트 기반** 톤을 지킨다. 관계 리스크 관리가 이 단계의 핵심이며, 단정형 추측이나 무리한 요구는 피한다.
</callout>

<callout icon="⚙️" color="yellow_bg">
	**보완(확인필요)** 답사 전·중·후 컨디션/이슈 로그를 어디에 남기는지(노션/시트 등) 운영 위치 명시 — 백업 원본에 기록 위치 명시 없음.
</callout>

**핵심 용어**: KOL — Key Opinion Leader, 공구 파트너 인플루언서 · 시딩 — KOL에게 항공·호텔을 무료 제공해 홍보 유도 · 바우처 — 항공·호텔 무료 제공 증빙(KOL 출발 시 사용) · 에어텔 — 항공+호텔 결합 상품(추가 액티비티 요청 판단 기준)
