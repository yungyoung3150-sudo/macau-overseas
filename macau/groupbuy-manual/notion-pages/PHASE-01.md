## STEP-01 · 일정·답사 확정 & 캘린더 등록

**목적**
이번 공구의 **답사(촬영)일 · 오픈일 · 마감일**을 확정하고, 팀 전체가 보는 캘린더에 등록해 모든 후속 일정의 기준선(역산 기준)을 만든다.

**담당**
- 선행(KOL 설득·일정 조율): 고대표님 · 김대표님 (대표 주도)
- 메인 (일정 확인·캘린더 등록): 김용성 · 정민님

**절차**

선행 전제 (대표님 주도 — 내 역할 없음)
- KOL 발굴·컨택·마카오 공구 제안·설득(시딩 포함)은 100% 대표님 주도다. 이 단계의 시작점은 "공구 건이 확정되고 대표님이 KOL과 시딩 일정을 조율한 시점"이다.
- KOL 확정·일정 공유가 단톡방에 올라오면 즉시 아래 본 절차로 진입한다.

본 절차
1. 대표님이 KOL과 조율한 **답사(=촬영) 기간**을 단톡방에서 확인 — 인플 일정 + 현지(마카오) 가능일이 교차 확인된 날짜.
2. 공구 **오픈일 / 마감일** 확정. 오픈 D-day가 셋업·홍보·확정 일정 전체의 역산 기준이 되므로 정확한 시·분까지 확인한다.
3. 확정한 일정(답사 · 오픈 · 마감)을 **캘린더에 등록** → 아래 캘린더 표준 등록 항목 참고.
4. 등록 후 담당 · 대표 · 인플에게 일정 공유.
5. KOL 정보 정리 시작 — **채널 링크 · 팔로워 수 · 인원 · 숙박 기간**. (이 정리물은 STEP-03에서 항공사/호텔 각 담당자에게 전달할 재료가 된다.)

<callout icon="⚠️" color="red_bg">
	**선행 단계는 대표님 영역** KOL 발굴·제안·설득은 100% 대표님 주도 — 내가 개입할 단계가 아니다. 일정이 단톡방에 공유되는 즉시 STEP-02 / STEP-03 재료 준비로 전환한다.
</callout>

- 일정 확인 즉시 후속 단계 재료 준비를 시작한다. 항공사(에어마카오 / 에어부산)·호텔(갤럭시 / 리스보아) 각 담당자에게 전달할 **KOL 정보를 미리 정리**해 둔다.

<callout icon="⚙️" color="yellow_bg">
	**보완(확인필요) — 캘린더 등록 SOP** 사내에서 어떤 캘린더(구글 / 네이버 / 사내 도구)를 정본으로 쓰는지 **확정 필요**. 다만 아래 **표준 등록 항목**을 정해두면 어느 툴이든 동일하게 적용된다.
	- 일정 제목 규칙: `[공구] {상품명} / {인플}` 예) `[공구] 갤럭시마카오 / 리얼커플`
	- 필수 필드: 답사기간 · 오픈 일시(정확한 시·분) · 마감 일시 · 담당자 · 인플 · 링크(노션)
	- 마일스톤 별도 표시: D-3(홍보 피드) · D-day(오픈) · 오픈+1일(분석) · +72h(확정 시작)
	- 알림: 오픈 1일 전·1시간 전 / 마감 1일 전
	- 👉 **할 일**: 사내 캘린더 1개 확정 + 위 항목으로 반복 일정 템플릿 한 번 만들어 저장.
</callout>

**핵심 용어**: KOL — Key Opinion Leader, 공구 파트너 인플루언서 · 공구 — 인플루언서 커머스 공동구매 · 시딩 — KOL에게 항공·호텔을 무료 제공해 홍보 유도 · 앵콜딜 — 기존 소재 재편집으로 반복 진행하는 재오픈 공구

- 판매기간 정리

## STEP-02 · 캘린더 확인 (아침 스크럼 전)

**목적**
매일 업무 시작 전 캘린더를 열어 오늘·이번 주 마일스톤을 확인하고, 아침 스크럼에서 보고할 한 줄을 정리한다. 1회성이 아니라 매일 반복하는 습관.

**담당**
- 메인: 김용성
- 확인: 정민님

**절차**
1. **매일 출근 직후, 아침 스크럼 전**에 캘린더를 연다.
2. **오늘 마일스톤** 확인 — 오픈 / 마감 / 답사 / 확정 등 임박 건.
3. **D-3 / D-day / 오픈+1 / +72h** 도래 건 체크.
	- 72h(72시간)는 STEP-24 해피콜·자동확정 트리거이므로 도래 여부를 매일 본다.
4. 도래한 마일스톤에 따라 해당 STEP으로 분기(예: 오픈 D-3 → STEP-26 홍보 피드 확인, 72h 도래 → STEP-24 해피콜).
5. 시딩 일정이 새로 확정됐다면 **KOL 정보 정리**를 함께 점검 — 채널 링크, 팔로워 수, 인원, 숙박 기간. (항공사·호텔 각 담당자 전달용 재료, STEP-03 준비)
6. **스크럼용 한 줄 정리**: "진행중 공구 N건, 오늘 핵심: ___" → 데일리노트 인박스에 기록.

<callout icon="⚠️" color="red_bg">
	**임박 건은 즉시 분기**
	- +72h 도래 건을 놓치면 STEP-24 자동확정/해피콜 타이밍이 밀려 CS·취소수수료 리스크로 직결된다. 매일 반드시 확인.
	- 오픈 D-3가 도래한 공구는 그날 STEP-26 홍보 피드 점검으로 넘어간다.
</callout>

- KOL 정보(채널·팔로워·인원·숙박 기간)는 시딩 일정 확정 즉시 정리 시작 — STEP-03 항공사·호텔 전달이 지연되지 않도록.

<callout icon="⚙️" color="yellow_bg">
	**보완(확인필요)** 사내에서 쓰는 캘린더 툴(구글 / 네이버 / 사내 도구)이 무엇인지 확정되면 확인 동선을 이 노트에 고정한다. (STEP-01 일정·답사 확정·캘린더 등록과 동일 항목)
</callout>

**핵심 용어**: 데일리 — 매일 반복하는 일상 점검 작업(여기선 캘린더 확인 습관) · KOL — Key Opinion Leader, 공구 파트너 인플루언서 · 시딩 — KOL에게 항공·호텔을 무료 제공해 홍보 유도 · 공구 — 공동구매. 진행 건수를 스크럼에서 보고
