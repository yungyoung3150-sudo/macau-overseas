# 📥 코끼리 반영 가이드 — 마카오 공동구매 매뉴얼 28단계

작성: 2026-06-26 (대표님 퇴근 후 야간 작업)

## 이게 뭔가요
예스트래블 마카오 공동구매 프로세스를 **최종 28단계 흐름으로 재정립**한, 코끼리(Main Vault)에 바로 넣을 수 있는 노트 세트입니다.
- `00_재정립-설계도.md` — 28단계 전체를 한 문서로 본 **본문 원본**(검토용).
- `vault-ready/` — 코끼리 v2 규칙(파일명 위키링크·콜아웃·이모지 신호등)에 맞춘 **개별 노트 세트**:
  - `PHASES/` — 8개 단계 개요
  - `STEPS/` — 28개 STEP 노트
  - `TERMS/` — 📖 용어 17개
  - `CS·응대/` — 문자 템플릿 (실문구는 확인필요)
  - `🐘 마카오 공동구매 프로세스 허브.md` — 전체 목차/대시보드
  - `🗂️ 마카오 공구 REF — 환경·확인필요.md` — 환경 사실 + 확정 필요 항목
  - `_QA-리포트.md` — 노트 자체 점검 결과
  - `_확인필요-질문리스트.md` — **대표님이 답해줘야 확정되는 것들** (아침에 이것부터)

## 왜 자는 동안 볼트에 직접 못 넣었나
볼트가 iCloud(`Mobile Documents`)에 있어 macOS 프라이버시(TCC)가 외부 프로세스 접근을 막습니다.
→ **`/Applications/Claude.app`에 전체 디스크 접근 권한(FDA)** 을 켜야 Claude가 볼트를 읽고 쓸 수 있습니다.

## 아침 반영 절차 (둘 중 택1)

### A안 — FDA 켜고 Claude가 직접 반영 (추천)
1. 시스템 설정 → 개인정보 보호 및 보안 → 전체 디스크 접근 권한 → **Claude 켜기** (없으면 `+`로 `/Applications/Claude.app` 추가)
2. macOS가 "종료 후 다시 열기" 요구하면 그렇게
3. Claude 다시 열고: **"코끼리 마카오 공구 매뉴얼 재정립 이어서"**
   → 제가 ① 기존 볼트 STEPS/PHASES 명명규칙 읽고 ② 이 노트들을 거기에 맞춰 반영 ③ 옛 22단계(A~Z) 노트와 대조해 대체/삭제 매핑까지 처리합니다.

### B안 — 직접 Finder로 끌어다 넣기 (권한 변경 없이)
1. Finder에서 `vault-ready/` 안의 `PHASES STEPS TERMS CS·응대` 폴더와 허브/REF 노트를
2. `iCloud~md~obsidian/Documents/Main Vault/🐘 코끼리 (해외영업팀 매뉴얼)/` 아래로 복사
3. 옵시디언에서 위키링크 자동 인식 확인

> ⚠️ 옛 STEPS(A~Z 22단계)와 **번호 체계가 다릅니다(이번 1~28)**. 중복을 피하려면 옛 STEP 노트는 보관(_ARCHIVE) 후 이번 세트로 대체하세요. A안으로 하면 제가 자동 대조해 드립니다.
