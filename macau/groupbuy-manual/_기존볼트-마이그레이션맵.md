> [!quote] 이 문서는?
> 기존 코끼리 볼트의 **22단계 매뉴얼**(실제 사내 절차·연락처·시스템 정보가 풍부)과, 사용자가 확정한 **신 28단계 흐름**을 1:1로 대조한 마이그레이션 맵이다.
> 결론 한 줄: **신 28단계 = 골격(흐름)이 더 정밀**, **기존 22단계 = 살(디테일·실무 노하우·연락처)이 더 풍부**. → 신 골격에 기존 디테일을 이식한다. 기존 노트를 버리지 말 것.

> [!warning] 표기
> - 기존 STEP은 `STEP-NN`(볼트 실제 파일명). 신 단계는 `신N`(설계도 1~28).
> - ⚠️ = 기존에 전혀 없어 **신규 집필**이 필요한 단계.
> - 🔁 = 기존 한 STEP이 신 여러 단계로 쪼개지거나, 신 한 단계가 기존 여러 STEP을 합치는 경우.

## 기존→신 매핑표

## 신 28단계 커버리지

신 28단계 각각에 기존 STEP이 매핑되는지. ⚠️ = 기존에 전혀 없어 **신규 집필** 필요.

| 신 단계 | 기존 매핑 | 비고 |
|---|---|---|
| 신1 일정·답사 확정·캘린더 등록 | STEP-02(일부) | 캘린더 등록 SOP는 기존에도 약함 → 보강 필요 |
| 신2 캘린더 확인(아침 스크럼 전) | STEP-02(일부) | ⚠️ **"매일 확인 습관"은 기존에 독립 단계로 없음** → 신규 |
| 신3 시딩 인플 항공·호텔 바우처 | STEP-03 + STEP-04(바우처) | 채널별 전달처 이식 |
| 신4 기본 상품 노션 제공·촬영 구성 확인 | STEP-04(기본노션) | "촬영 필요 구성 묻기"는 신규 추가분, 기본노션 디테일은 기존 |
| 신5 답사 전중후 인플 컨디션 체크 | STEP-05 | "전·중·후 3구간 체크"는 신규 프레임, 현지대응은 기존 |
| 신6 패키지 제안·역제안 컨설팅 | STEP-06 + STEP-07(일부) | 인스타 피드 분석 노하우 이식 |

| 신8 최저가 모니터링 | STEP-08(앞부분) | 수화물 포함가 함정 이식 |
| 신9 요금 측정(초안) | STEP-08(중간) | 원가·마진 프레임은 ⚙️보완 상태 |
| 신10 요금 대표 컨펌(공헌이익률) | STEP-08(본부장 단계) | 기존은 "본부장 요금표"로 통합돼 있음 |
| 신11 요금표 인플 전달 | STEP-08(끝)·STEP-09(일부) | 후킹가/요금표 KOL 재공유 |
| 신12 상점 확인·상점명 변경 | (없음) ⚠️ | ⚠️ **기존에 "상점명 변경" 단계 없음**(기존은 JBS 일정배치 중심) → 신규. 상점 플랫폼 확정 필요 |

## 용어(TERMS) 충돌

기존 볼트 TERMS는 **무접두사 파일명**(`APIS.md`, `시딩.md`, `공구.md`…)에 `[[APIS|APIS]]` 형식으로 본문 전체에서 링크됨. 내가 야간에 만든 staging은 **`📖 ` 접두사**(`📖 APIS.md` …)라 파일명이 달라 **위키링크가 깨진다**.

| 용어 | 기존(무접두사·실사용 중) | 내 야간본 | 권고 |
|---|---|---|---|
| APIS | ✅ `APIS.md` | `📖 APIS.md` | **기존 유지, 📖 폐기** |
| PNR | ✅ `PNR.md` | `📖 PNR.md` | **기존 유지, 📖 폐기** |
| 바우처 | ✅ `바우처.md` | `📖 바우처.md` | **기존 유지, 📖 폐기** |
| 시딩 | ✅ `시딩.md` | `📖 시딩.md` | **기존 유지, 📖 폐기** |
| 상세페이지 | ✅ `상세페이지.md` | `📖 상세페이지.md` | **기존 유지, 📖 폐기** |
| 해피콜 | ✅ `해피콜.md` | `📖 해피콜.md` | **기존 유지, 📖 폐기** |
| 공헌이익 | ✅ `공헌이익.md` | `📖 공헌이익률.md` | **기존 `공헌이익` 유지**. 이름도 다름(이익 vs 이익률) → 📖 폐기 |
| 최저가 모니터링 | (기존 용어노트 없음·STEP-08서 서술) | `📖 최저가 모니터링.md` | 신규 용어로 **가치 있음** → 단 **접두사 떼고 `최저가 모니터링.md`로 신설** |

> [!warning] 결론
> - **충돌 10개(APIS·PNR·바우처·시딩·상세페이지·해피콜·공헌이익 등)는 기존 무접두사 노트를 정본으로 유지하고, 내 `📖 ` 버전은 폐기.**
> - **기존에 없던 신규 용어**(상점·판매코드·히든·데일리·최저가모니터링·서버증축·세일즈방·클라이언트·자동확정·중간확정)는 가치 있으니 살리되, **반드시 `📖 ` 접두사를 떼고** 기존 명명규칙(무접두사)에 맞춰 신설. 그래야 본문 `[[상점|상점]]` 링크가 깨지지 않음.
> - 기존 추가 용어(KOL·역제안·에어텔·세미패키지·후킹가·소구포인트·앵콜딜·하드블록·인펀트·구글폼·SCM·JBS·E티켓·QR발권)는 **전부 유지**(신 흐름에서도 쓰임).

## 명명·구조 권고

기존 규칙(① `STEP-NN` 0패딩 2자리 ② PHASES 9섹션 ③ TERMS 무접두사 ④ `STEP-NN / 22` 푸터 네비 ⑤ 허브 `🐘 해외영업팀 메뉴얼 허브.md`)을 **유지하면서** 28단계로 가는 방안.

**1) STEP 파일 — 22 → 28 재배열**
- 기존 `STEP-01~22.md`를 신 번호로 **전면 재매핑 후 STEP-01~28로 재작성**(파일명 규칙 동일, 0패딩 유지: `STEP-08.md`).
- 신 번호가 기존과 어긋나므로 **파일 내용을 신 흐름 기준으로 재배치**하고, 위 §1 매핑표를 각 노트 상단 주석(`> 기존 STEP-NN에서 이식`)으로 남겨 추적성 확보.
- 푸터 네비 `STEP-NN / 22` → **`STEP-NN / 28`로 일괄 갱신**. `◀ STEP-NN | STEP-NN ▶` 양방향 링크도 28개 체인으로 재연결.

**2) PHASE — 기존 9섹션 → 신 8 PHASE 조정**
- 기존 PHASES는 9개(01기획&인플~09참고창고). 신 설계도는 8 PHASE(01일정답사~08CS확정).
- 권고: **기존 09(참고 자료 창고)는 PHASE가 아니라 REF**이므로 PHASE에서 분리 유지. 나머지 01~08을 신 8 PHASE로 **재명명·재경계**:
  - 신01 일정·답사(1~2) / 신02 시딩지원(3~5) / 신03 구성·컨설팅(6~7) / 신04 요금설계·승인(8~11) / 신05 판매셋업(12~17) / 신06 오픈 D-3~D(18~21) / 신07 분석·독려(22) / 신08 CS·확정(23~28).
  - 각 PHASE 노트 frontmatter `phase:` 값과 STEP frontmatter `phase:` 값을 **동일 문자열로 일치**시켜 Obsidian 그룹핑 유지.

**3) TERMS — 무접두사 규칙 고수**
- 신규 용어도 `상점.md`·`판매코드.md`처럼 **접두사 없이** 신설. `📖 용어 인덱스.md`(인덱스 1장만 📖 허용)에 ㄱㄴㄷ 항목으로 추가.
- 내 야간본 `📖 *.md` 17개는 **인덱스 1장 외 전부 접두사 제거 후 병합/폐기**.

**4) 허브 STEP 네비 갱신**
- `🐘 해외영업팀 메뉴얼 허브.md`의 22단계 목차·진행 표를 **28단계로 교체**. PHASE→STEP 트리, "STEP-NN / 28" 카운트, 신규 8개 단계(신2·7·12·13·16·18·19·26) 행 추가.
- 허브에 **여행자보험·QR발권(기존 STEP-21·22)을 어디에 두었는지** 명시(신 단계 삽입 or REF 분리).

**5) 누락 방지 — REF 분리 보존**
- 단계가 아닌 실무 자산(JBS/SCM/호텔부킹 URL, 호텔 투숙규정, 🔒결제카드, 트래블로버·클룩 로그인, 모객현황 시트, 해피콜 시트)은 **🗂️REF 노트로 모아 보존**하고 각 STEP에서 `🔗 관련 문서`로 링크. 신 STEP 본문이 깔끔해지고 기존 디테일이 살아남음.
