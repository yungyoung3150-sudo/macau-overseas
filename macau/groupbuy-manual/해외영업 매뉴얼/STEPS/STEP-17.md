# 📌 STEP-17: 예약 발신 템플릿 설정 (구글폼·예약메시지)
> 공구별 여권 수집용 구글폼을 신규 생성하고, JBS 예약 메시지 템플릿의 폼 링크를 새 폼으로 교체·활성화해 오픈 직후 구매 → 예약정보 입력 동선을 미리 완성한다.

---
## 👤 담당자
| 역할 | 담당자 |
|------|--------|
| 메인 | 김용성 |

## 📋 절차
1. **여권 정보 입력용 구글폼 신규 생성** — 이번 공구 전용으로 새로 만든다. 이전 공구 폼을 재사용하지 않는다.
2. **수집 필수항목 고정** — 후속 단계([[STEP-26|STEP-26]] 여권정보 미입력 문자 · [[STEP-27|STEP-27]] PNR APIS 제작)에서 쓰는 항목 기준으로 폼 항목을 구성한다.
   - ⚙️ 보완(확인필요): 이번 공구의 구체 필수항목 목록(여권 영문명·여권번호·생년월일·국적 등)을 오픈 전에 확정해 고정.
3. **JBS 예약 메시지 템플릿 접속** — [[JBS|JBS]] (jungle.booking.stayjanda.cloud)에서 예약 메시지 템플릿을 연다.
4. **템플릿 내 구글폼 링크를 새 폼으로 교체** — 1에서 만든 신규 폼 URL로 기존 링크를 덮어쓴다.
5. **기능 켜기(활성화) 확인** — 메시지 발송 기능이 활성 상태인지 점검한다.
6. **테스트 예약으로 정상 발송 확인** — 구매 완료 → 예약 메시지 발신 → 신규 구글폼으로 연결되는지 한 번 끝까지 돌려본다.

## ⚠️ 주의사항
> [!warning] 폼 링크 교체 누락 = 대형 CS
> **기존 폼 링크를 그대로 두면 이전 공구 폼으로 여권이 수집된다.** 새 공구마다 반드시 신규 폼을 생성하고 JBS 템플릿 링크를 교체할 것.

- 현재 사용 중인 폼 링크(참고):
  - 마카오 일반: [내부 링크 삭제]
  - 마카오 리스보아: [내부 링크 삭제]
- 여기서 수집한 예약정보가 이후 단계의 기준 데이터가 된다. 수집 필수항목이 빠지면 [[STEP-26|STEP-26]] 추출과 [[STEP-27|STEP-27]] APIS 제작에서 누락이 그대로 이어진다. 필수항목은 오픈 전에 고정하고, 오픈 후 임의 변경은 피한다.
