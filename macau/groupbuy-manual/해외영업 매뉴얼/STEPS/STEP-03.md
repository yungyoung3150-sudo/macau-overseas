# 📌 STEP-03: 시딩 항공·호텔 가능 확인 → 바우처 전달
> KOL 시딩 가능 일정을 채널별 담당자에게 전달해 항공·호텔 가능 여부를 확인하고, 받은 바우처를 검증해 KOL에게 전달한다.

---
## 👤 담당자
| 역할 | 담당자 |
|------|--------|
| 메인 | 김용성, 정민님 |
| 리스보아 특전 구성 | 리스보아 담당 이사님 |

## 📋 절차
1. **KOL 정보 정리** — 채널 링크, 팔로워 수, 인원, 숙박 기간, 항공 필요 여부 (전 단계에서 정리한 자료 재확인)
2. **채널별 시딩 일정 전달** (항공·호텔 가능 여부 확인 요청)
   - 에어마카오 → 에어마카오 담당자 톡방에 전달
   - 에어부산 → 에어부산 단톡방에 전달
   - 갤럭시 → 갤럭시 담당자님에게 전달
   - 리스보아 → 리스보아 담당 이사님에게 전달
3. **가능 여부 회신 확인** — 좌석·요일·박수 규칙(출발 요일별 귀국일) 점검. 정확한 편명·스케줄·박수 규칙은 사내 마카오 항공 스케줄 자료를 기준으로 본다. ⚙️ 보완(확인필요): 참조할 항공 스케줄 노트가 볼트에 들어오면 위키링크로 연결.
4. **바우처 수령**
   - 에어마카오·에어부산 항공 바우처 (에어마카오 담당자 톡방 / 에어부산 단톡방)
   - 갤럭시 호텔 바우처 (갤럭시 담당자님)
   - 리스보아 바우처 → **이사님 특전 구성 완료 후** 수령 (리스보아 담당 이사님)
5. **바우처 내용 검증** — 항목별로 일치 확인
   - 이름(여권 영문) / 날짜 / 항공 편명 · 호텔 객실 타입 / 인원
6. **KOL에게 바우처 전달** + 체크인/수속 안내
   - 리스보아 특전 → 이사님 확인 완료 후 KOL에게 추가 전달
7. 기본 상품 노션은 [[STEP-04|STEP-04]]에서 별도 전달 (수화물·호텔 구성·조식가·인펀트가·항공편·셔틀·포토스팟)

## ⚠️ 주의사항
> [!warning] 리스보아 바우처는 이사님 확인 전 절대 먼저 보내지 말 것
> 리스보아는 리스보아 담당 이사님이 호텔 특전을 직접 구성해주신다 → 이사님 확인 완료 전 KOL에게 먼저 발송 금지.

> [!warning] 바우처 이름 = 여권 영문과 반드시 일치
> 바우처 이름이 여권 영문과 다르면 발권·체크인이 거부될 수 있다. **여권 영문을 먼저 확보한 뒤 신청**하고, 수령한 바우처는 이름·날짜·편명·인원을 한 번 더 대조한다.

- 전달 전 인원 수·일정 반드시 재확인
- 항공 스케줄은 변동될 수 있으므로 공구 전 반드시 재확인
