# 📌 STEP-12: 상점 확인 & 상점명 변경
> 이번 공구를 담을 상점(판매 채널)을 확인하고, 상점명을 이번 건에 맞게 변경한다.

---
## 👤 담당자
| 역할 | 담당자 |
|------|--------|
| 메인 | 김용성 |
| ⚙️ 보완(확인필요) | 상점 운영 권한 보유자 — 선임이 기본 틀을 잡아두는 구조와 동일한지 확인 |

## 📋 절차
1. [[STEP-11|STEP-11]](요금표 인플 전달) 완료 확인 — 요금표가 인플에게 전달되어 판매 셋업 단계로 넘어온 상태에서 시작한다.
2. 이번 공구를 담을 [[상점|상점]](판매 채널) 접속 → **사용할 상점 확인**.
3. 상점 상태 점검 — 활성 여부, 연결 정상 여부(노출/링크가 정상 작동하는지) 확인.
4. **상점명을 이번 공구에 맞게 변경** — 직전 공구의 이름이 남아 있으면 이번 건 정보로 교체.
5. 변경 후 상점명·노출 상태를 다시 한번 확인하고 다음 단계([[STEP-13|STEP-13]] 판매코드 생성)로 인계.

> ⚙️ 보완(확인필요): 상점 플랫폼 정확히 확정(Wix? 자사몰?) — 현재 Wix MCP 연결 상태. 확정 후 접속 경로·메뉴 위치를 본 절차에 보강할 것.

## ⚠️ 주의사항
> [!warning] 직전 공구명이 그대로 남으면 사고
> 상점명을 안 바꾸면 고객이 **이전 공구 상점명/정보로 인식**하게 되어 혼선·CS로 직결된다. 상점명 변경은 빠뜨리지 말 것.

- 상점 **상태(활성)·연결 정상 여부**를 반드시 확인 — 비활성/링크 깨짐 상태로 다음 단계 진행 시 오픈 직전 발견되면 대응 시간이 부족하다.
- ⚙️ 보완(확인필요): 상점과 [[판매코드|판매코드]]·판매 링크가 어떻게 연결되는지(상점 변경이 코드에 영향 주는지) 확정 필요 — STEP-13와의 선후 관계 점검.
