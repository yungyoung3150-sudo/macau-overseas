# 📌 STEP-24: 72시간 후 예약 확정 (해피콜·자동확정)
> 구매 후 72시간이 지난 건의 항공·호텔 실제 예약 가능 여부를 재확인 → 가능 시 자동 확정(예약 진행), 불가 시 즉시 명확히 안내.

---
## 👤 담당자
| 역할 | 담당자 |
|------|--------|
| 메인 | 김용성, 정민님 |

## 📋 절차

### 전체 흐름
```
예약에 필요한 사이트 준비
→ 고객 명단에서 일정 확인
→ 항공권 구매 가능 여부 체크
→ 호텔 객실 구매 가능 여부 체크
→ 호텔 가능하면 바로 Reserve 누름
→ 총 결제 금액이 공구 시트 금액과 일치하는지 확인
→ 결제 카드 등록
→ 고객 개인정보 국적 먼저 수정
→ 고객 명단(해피콜 시트) 확인 → 성·이름 복사 붙이기
→ 호텔 예약 확정
→ 공구 스프레드시트에서 상태를 '해피콜 완료' 체크
```

---

### 상세 절차

**1. 72시간 도래 건 추출 & 사이트 준비**
- 구매 후 **+72시간**이 지난 건(건별 기준)을 [[해피콜|해피콜]] 시트에서 추출 → [[자동확정|자동 확정]] 절차 시작.
- 해피콜 메모에 요청 있는 고객(예: "예약 확정 전 꼭 전화 주세요")은 전화 후 진행, 그 외는 자동 확정으로 진행.
- 마카오 호텔 부킹(shijicloud): [내부 시스템 주소 삭제]
- 에어마카오 좌석 수량(모객현황) 스프레드: [내부 링크 삭제]
- 마카오 해피콜 시트: [내부 링크 삭제]
- 해당 공구 스프레드시트

**2. 고객 명단 일정 확인**
- 출국일·귀국일 확인 → 2박3일 or 3박4일 구분
- 인원 수 확인 (수량 체크)
- ⚠️ 성인 3명 조회 불가 → 성인 2 + 소인 1로 예약 후 호텔 측에 성인 3명이라고 별도 고지

**3. 항공 예약 가능 여부 확인 ([[SCM|가용 확인 채널]])**
- **에어마카오** — 모객현황 구글 스프레드에서 해당 일정 좌석 가용 여부 체크
- **에어부산** — 단톡방에 확정 가능 여부 요청
- 채널마다 확인 방법이 다름 — 혼동 주의

**4. 호텔 객실 가용 여부 체크**
- New Booking → Room Availability → 선택 사항 입력
- 성인 2명 이상 조회 불가 → 성인 2명 + 객실 수 올리기
- **조식 포함/미포함 구분 확인 필수** (가격 차이 큼)
- 예약 가능 → **Reserve 버튼 클릭**
- ⚠️ 특이 요청 사항 확인 (예: "예약 확정 전 꼭 전화 주세요")
- 갤럭시(안다즈/브로드웨이) 물량 부족 시 → 갤럭시 담당자님께 추가 물량 요청 / 리스보아는 리스보아 담당 이사님께 확인

**5. 호텔 예약 대금 지불** — 카드정보 사내 보안노트(자격증명은 담당자에게 요청)
```
결제 카드 입력:
- 카드 종류: MA
- 번호·만료·명의: 🔒 보안 노트 참조
```
- 객실 금액(MOP)과 공구 스프레드 결제 금액 일치 확인
- 고객 국적 KR로 변경
- 마카오 해피콜 시트에서 성·이름 복붙 후 결제

**6. 최종 확정 처리**
- 공구 스프레드 → 상태: **해피콜 완료** 변경 (건별 확정/불가/보류 기록)
- 확정 불가 시 → 항공·호텔 재요청 or 고객에게 날짜 변경 유도 → **즉시·명확히 안내** (다음: [[STEP-25|중간 확정 안내 문자]])

> [!warning] 호텔 투숙 규정 (예약 세팅 시 필수 확인)
> **안다즈 마카오** — 성인 3명 이상 = Extra Bed 자동 발생(원하지 않아도 추가비용) / 성인 2+소인 2 = 추가요금 없음. 시스템에서 성인 3 입력 불가 → 성인 2+소인 1로 조회 후 예약. Extra Bed 발생 시 갤럭시 어드민으로 이메일(Extra Bed request) 필수. 안다즈 Admin은 취소·변경 불가(예약만 가능).
> **브로드웨이 마카오** — 성인 2+소인 1 = MAX(엑스트라베드 공간 없음) / 성인 3명 = 객실 2개 필요. 성인 5명이면 객실 2~3개 필요 → 고객 사전 안내 필수.

## ⚠️ 주의사항
- **대금과 연결되어 있으므로 항상 더블체크, 빠르게 하지 말고 천천히**
- **72시간 기준 정확히 체크** — 72시간 이전 확정 시 취소 수수료 발생 가능
- 확정 불가 건은 고객에게 빠르게 안내 (대기 길어지면 CS 악화)
- 해피콜 메모 확인 — 요청 있는 고객은 전화 후 진행
- SCM 확인 없이 확정 금지 → 오버부킹 시 전액 보상 책임

> [!tip] ⚙️ 보완(확인필요)
> 신 흐름의 분기 정의가 사내 실제 운영과 맞는지 확정 필요(맞으면 ⚙️ 제거 후 본문 고정).
> - **해피콜(전화) vs 자동 확정 분기 기준** — 어떤 조건/건이 해피콜로 가고 어떤 건이 자동 확정인지. (현재 운영: 해피콜 메모에 요청 있는 건만 전화, 그 외 자동)
> - **자동 확정의 정확한 동작** — 무엇이 자동 처리되고 어디서 트리거되는지.
