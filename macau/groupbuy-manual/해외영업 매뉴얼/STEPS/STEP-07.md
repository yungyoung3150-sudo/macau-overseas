# 📌 STEP-07: 최종 구성 노션 제작
> [[STEP-06|◀ STEP-06]]에서 인플과 1~2회 역제안을 거쳐 합의된 최종 패키지를 **최종 구성 노션** 하나로 문서화한다. 이후 요금·상세페이지·CS가 전부 이 노션을 단일 사실 원본(SoT)으로 삼는다.

---
## 👤 담당자
| 역할 | 담당자 |
|------|--------|
| 메인 | 김용성, 정민님 |
| 최종 확인 | 대표님 · 인플(KOL) |

## 📋 절차
1. [[STEP-06|◀ STEP-06]] 컨설팅으로 **최종 구성안이 합의**된 상태에서 시작한다.
2. 최종 구성 노션을 작성하고, 다음 항목을 빠짐없이 명시한다.
   - 호텔 / 객실
   - 박수
   - 항공편 (NX / BX 등)
   - 포함 / 불포함
   - 옵션
   - 유의사항 (수화물 규정·조식가·인펀트가·셔틀·포토스팟 등 기본 노션 항목 포함)
3. **노션 = 사실 원본(SoT)** 원칙 적용 — 발리 공구 사례와 동일하게, 묘사·조건은 노션에 적힌 사실만 기준으로 삼고 임의로 살붙이지 않는다.
4. 이 최종 구성 노션을 바탕으로 **[[소구포인트|소구포인트]]** 초안을 함께 정리한다. (아래 §소구포인트 체크리스트 — 기존 STEP-07 이식분)
5. 관계자(대표님·인플)에게 노션을 공유하여 **최종 확인**을 받는다.
6. 산출물인 **최종 구성 노션 URL**을 후속 단계([[STEP-08|STEP-08 ▶]] 최저가 모니터링부터 요금·상세페이지·CS까지)의 단일 기준으로 전달한다.

## ⚠️ 주의사항
> [!warning] 이 노션이 곧 사실 원본(SoT)
> 이후 요금 설계·상세페이지 제작·CS 응대는 모두 이 노션을 보고 진행한다. 노션에 없는 내용을 다른 단계에서 임의로 채워 넣으면 단계 간 사실이 어긋난다. 구성이 바뀌면 **반드시 노션을 먼저 갱신**하고, 노션을 기준으로 후속 단계를 다시 맞춘다.

- 소구포인트 작성 전 KOL 인스타 피드 반응을 반드시 확인한다 ([[STEP-06|STEP-06]] 역제안 결과 기반).
- [[후킹가|후킹가]]·[[상세페이지|상세페이지]] 준비 완료 시점을 KOL에게 미리 안내한다 (KOL 일정 조율을 위해). 실제 후킹가 산출은 [[STEP-08|STEP-08]]~[[STEP-11|STEP-11]](요금 설계·전달)에서 진행된다.

## 📝 소구포인트 체크리스트 (기존 STEP-07 이식)

확정된 최종 구성을 기준으로, 아래 항목을 순서대로 확인하고 소구포인트에 반영한다.

- [ ] **유류세 없음** 강조 → "요즘 같은 시기에 부담 없이 예약 가능"
- [ ] **에어텔 / 세미패키지 선택 가능** 여부 명시 (인플마다 다름 — 사전 확인)
- [ ] **지방 출발 (에어부산 / 부산 출발)** 여부 — 에어부산 좌석 확보 여부 확인 후 기재
- [ ] **워터파크 무료 이용** 여부 (예: 갤럭시 그랜드 덱 / 시즌별 운영 확인)
- [ ] **호텔 퀄리티 포인트** — 안다즈(신축·고급) vs 브로드웨이(가성비·브로드웨이 스트리트) 선택 가능
- [ ] **조식 포함 여부** (미포함 시 → 브로드웨이 약 15,000원 / 안다즈 약 50,000원 추가 안내)
- [ ] **갤럭시 바우처 혜택** 등 호텔 특전 명시
- [ ] **인펀트 추가 비용** 명시 (에어마카오 23만원 / 에어부산 10만원)
- [ ] **판매기간** 명확하게 기재

---

## ✍️ 실제 홍보 포인트 예시 (쪼기 기준)

```
1. 판매기간 5/11~8/31
2. 그랜드 덱 (워터파크 오픈중) 무료 이용가능
3. 에어텔 / 세미 패키지 취향 따라 선택 가능
4. 지방 출발자들 위해 에어부산 좌석 확보 완료
✔ 유류세 추가 없이 확정가
→ 요즘 같은 시기에 부담 없이 바로 예약 가능한 마지막 기회

✔ 마카오 '그랜드 덱' 리조트 무료 이용
→ 8월 말까지 여유 있게 사용 가능해서 활용도 최고
```

> 위는 예시. 공구마다 KOL 성격·상품 구성에 맞게 수정.
