# 📌 STEP-13: 판매코드 생성·검증·전달
> 이번 공구용 판매(상품) 코드를 만들고, 코드 ↔ 상품·가격·링크 연결이 정상 동작하는지 검증한 뒤 인플에게 전달한다.

---
## 👤 담당자
| 역할 | 담당자 |
|------|--------|
| 메인 | 김용성, 정민님 |
| 검수 | 김용성 (전달 전 클릭 테스트) |

> ⚙️ 보완(확인필요): 판매코드 발급 권한·플랫폼(상점 시스템 기준)이 선임 셋업인지 본인 작업인지 사내 확정 필요. 기존 [[JBS|JBS]] 일정배치는 "보통 선임이 기본 틀을 잡아둠"이었음 — 판매코드도 동일 분담인지 확인.

## 📋 절차
1. 선행 확인: [[STEP-12|STEP-12]]에서 이번 공구용 [[상점|상점]]이 준비되고 상점명이 이번 건에 맞게 변경되어 있는지 확인.
2. 선행 확인: 요금표가 확정되어 인플에게 전달된 상태인지 확인([[STEP-11|STEP-11]]) — 코드에 연결할 가격의 근거.
3. 판매(상품) [[판매코드|판매코드]] 생성.
4. 이상 여부 확인 — 코드 ↔ 상품 매핑이 정상인지 (이번 공구 상품과 코드가 맞물리는지).
5. 이상 여부 확인 — 코드 ↔ 가격이 정상인지 (요금표 확정가와 일치하는지).
6. 이상 여부 확인 — 코드 ↔ 링크가 정상인지.
7. **실제 클릭 테스트** — 코드/링크를 직접 눌러 정상 판매 페이지로 이동하는지, 표시 가격이 요금표와 같은지 눈으로 확인.
8. 이상 없음 확인 후 인플에게 판매코드 전달.

> ⚙️ 보완(확인필요): 판매코드 생성 위치·발급 절차(상점 플랫폼 기준)의 구체 단계는 사내 확정 후 본문 보강. 정의는 [[판매코드|판매코드]] 참조.

## ⚠️ 주의사항
> [!warning] 코드 연결 오류 = 오픈 직후 매출 직결 손실
> 판매코드의 상품·가격·링크 연결 오류는 오픈 직후 매출 손실로 곧장 이어진다. 눈으로 매핑만 확인하지 말고 **반드시 실제 클릭 테스트**로 정상 페이지 도달·정상 가격 노출까지 검증한 뒤 인플에게 전달한다.

- 코드에 연결되는 가격은 STEP-11에서 확정된 요금표와 **반드시 일치**시킬 것 — 오기입 시 [[공구|공구]] 오픈 후 정정 불가에 가까운 클레임으로 번짐.
- 이전 공구의 코드·링크를 그대로 재사용하지 말 것(이전 건으로 연결되는 사고 방지). 이번 공구 [[상점|상점]] 기준으로 새로 발급.
