# 📌 STEP-14: 상세페이지 제작 & 셋팅
> 최종 구성 노션(SoT)을 근거로 상품별 상세페이지를 제작하고, 품목 누락·가격 오기입을 검수한 뒤 상점에 셋팅·연결한다.

---
## 👤 담당자
| 역할 | 담당자 |
|------|--------|
| 메인 | 김용성 |
| 검수 협업 | 정민님 |
| 수정 요청 | 팀장님 |

## 📋 절차
1. **자체 편집기로 상세페이지 제작** → 상품별 themed 산출물(예: galaxy-macau, lisboa-palace, selectum-noa)
2. **최종 구성 노션(SoT) 기준으로 사실 일치 확인**: 가격 · 포함/불포함 · 유의사항
3. **각 품목이 빠짐없이 첨부됐는지 순서대로 확인** (기존 STEP-11 검수 — CS 폭발 방지 필수 체크)
4. 내용 정확성 재확인: 가격, 일정, 포함 내역 — 특히 [[후킹가|후킹가]]와 상세페이지 가격 불일치 여부
5. 문제 발견 시 팀장님께 수정 요청 → 수정 완료 후 재확인
6. **상점에 상세페이지 셋팅·연결**
7. 셋팅 후 실제 페이지에서 표시 확인 (노션 원문과 최종 대조)

## ⚠️ 주의사항
> [!warning] 품목 누락 = 오픈 후 CS 폭발
> 상세페이지에 품목이 하나라도 빠지면 오픈 후 CS가 폭발한다. 공구 시작 전 반드시 100% 체크할 것.

- **가격 오기입 특히 주의** — 후킹가와 상세페이지 가격이 불일치하면 고객 혼란·클레임으로 직결.
- **가격·포함/불포함·유의사항은 반드시 노션(SoT)을 기준**으로 한다. 상세페이지가 SoT이 아니므로, 불일치 시 노션을 우선으로 정정.

> [!warning] 자동저장이 소스 텍스트 편집을 덮어쓸 수 있음
> 편집기의 자동저장(window.name)이 소스 텍스트 직접 편집을 덮어쓸 수 있다. 소스 텍스트를 직접 수정할 때는 라이브 동기화에 주의한다.

- ⚙️ 보완(확인필요): 상점에 상세페이지를 연결하는 구체 셋팅 경로·연동 방식은 신규 단계라 근거 미확보 → 실무 확인 후 보강.
