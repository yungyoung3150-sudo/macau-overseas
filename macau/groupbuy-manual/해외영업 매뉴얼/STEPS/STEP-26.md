# 📌 STEP-26: 여권정보 미입력 고객 독촉 문자
> 발권에 필요한 여권정보 미입력 고객을 추려 입력 요청 문자를 발송, 발권 누락을 막는다. 목표는 여권 미입력자 0.

---
## 👤 담당자
| 역할 | 담당자 |
|------|--------|
| 메인 | 김용성 |
| 지원 | 정민 |

## 📋 절차
1. 예약 폼([[STEP-17|STEP-17]]에서 세팅한 공구별 신규 구글폼) 응답 데이터 확인
   - 현재 사용 중인 여권 수집 폼 링크:
     - 마카오 일반: [내부 링크 삭제]
     - 마카오 리스보아: [내부 링크 삭제]
   - ⚠️ 폼 링크가 직전 공구 것이면 [[STEP-17|STEP-17]]에서 교체했는지 먼저 확인(이전 공구 폼으로 수집 시 대형 CS)
2. 폼 응답과 [[STEP-25|STEP-25]] 중간 확정 명단을 대조해 **여권정보 미입력자 추출**
3. 미입력자에게 입력 요청 문자 발송 — **입력 마감 기한 명시**
4. 마감 후 미응답자 **재안내**(전화 우선)
5. 수령한 여권값 검증
   - 여권 영문 철자·생년월일 **오타 확인**
   - 동행자(동반 인원) 누락 여부 확인
   - [[인펀트|인펀트]](만 2세 미만 유아)는 여권/APIS 별도 처리 대상인지 확인
6. 검증 완료된 여권 영문명·생년월일을 [[STEP-27|STEP-27]] [[PNR|PNR]]·[[APIS|APIS]] 제작 전까지 확정

⚙️ 보완(확인필요): 독촉 문자 실문구는 [[CS 대응 문자 ( 패턴 )|CS 대응 문자 패턴]]에서 확정 후 링크. (민증 수집용 단체문자 문구는 보험 단계 참고: [[단체문자 (여행자보험) 멘트|단체문자 (여행자보험) 멘트]])
⚙️ 보완(확인필요): '미입력자' 판정 항목 — 여권 영문·생년월일·여권번호·유효기간 중 어디까지 필수인지 예약 폼 구성에 맞춰 확정.
⚙️ 보완(확인필요): 입력 마감 기한의 기준일(출국 D-? 또는 PNR 작업일 기준)과 재안내 횟수·간격.

## ⚠️ 주의사항
> [!warning] 여권 영문·생년월일 오타 = 발권 오류
> 입력받은 여권 영문 철자와 생년월일이 틀리면 그대로 발권 오류로 이어진다. 수령값은 반드시 검증하고, 영문명은 [[STEP-27|STEP-27]] PNR·APIS 제작 전에 확정한다.

- 여권 미수집·미응답 칸을 **자의적으로 추정해 메우지 말 것** → 반드시 전화로 직접 확인(기존 민증 수집 노하우와 동일).
- 영문명 오타가 발권 이후 발견되면 항공사에 별도 변경 요청 양식이 필요하다([[여권 영문명 변경 (에어마카오)|여권 영문명 변경]] 참고). 발권 전에 잡는 것이 최선.
- 발권 데드라인 역산: 여권 확보가 늦으면 [[STEP-27|STEP-27]] PNR/APIS 일정이 밀린다. 미입력자 0 달성을 본 단계에서 마무리.

## 📎 핵심 용어
| 용어 | 한 줄 설명 |
|------|-----------|
| [[APIS|APIS]] | 사전입국심사정보, 발권에 여권정보 필요(여권 없으면 임시번호 처리) |
| [[PNR|PNR]] | 항공 예약 기록, 여권 영문명 확정 후 제작 |
| [[구글폼|구글폼]] | 공구별 신규 생성하는 여권정보 수집 폼 |
| [[인펀트|인펀트]] | 만 2세 미만 유아, 여권·APIS 별도 처리 확인 |
