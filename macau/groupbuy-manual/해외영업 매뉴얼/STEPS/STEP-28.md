# 📌 STEP-28: 항공권·E티켓 & 호텔 예약번호 최종 확정 안내
> 에어마카오는 항공권 번호, 에어부산은 E티켓을 수령해 호텔 예약번호와 함께 고객별로 매칭·정리하고, 최종 예약 확정 안내 문자를 발송해 공구 fulfillment를 마무리한다.

---
## 👤 담당자
| 역할 | 담당자 |
|------|--------|
| 메인 | 김용성, 정민님 |

## 📋 절차

### 1) 항공권 번호 / E티켓 수령
1. **에어마카오**: 에어마카오 담당자로부터 **항공권 번호(13자리)** 수령
2. **에어부산**: 에어부산 시스템에서 **E티켓(PDF)** 수령
3. 형식 혼동 금지 — 에어마카오 = 항공권 번호 / 에어부산 = E티켓 (PDF)

| 항목 | 에어마카오 | 에어부산 |
|------|-----------|---------|
| 발급 형태 | 항공권 번호 (13자리) | E티켓 (PDF) |
| 발급 주체 | 에어마카오 담당자 | 에어부산 시스템 |
| 고객 전달 방법 | 번호 문자 전송 | PDF 첨부 발송 |

### 2) 호텔 예약번호 + 건별 매칭 정리
4. 항공권 번호(에어마카오) 또는 E티켓(에어부산) + **호텔 예약번호**를 고객별로 정리
5. 구글 시트에 **고객 ↔ 항공 ↔ 호텔** 매칭 입력
6. 고객 성명·여정 정보(날짜·편명·이름)를 다시 한번 **육안 재확인** (매칭 오류 방지)

### 3) 최종 확정 안내 문자 발송
7. 최종 예약 확정 안내 메시지 작성 (구성 내용은 아래 참고)
8. 고객에게 **개별 발송** — 출국일 기준 **1주일 전**
9. 요청 사항 있는 고객(전화 먼저 등) 확인 후 발송
10. 발송 후 해당 건 **동그라미(○) 체크** → 공구건 마무리
11. **전 고객 발송 완료** 확인 → 공구 fulfillment 종료

> [!example] 💬 최종 확정 문자 구성 (포함 내용)
> ```
> - 고객님 항공권 번호 (에어마카오) 또는 E티켓 첨부 (에어부산)
> - 호텔 예약 번호
> - 출국일·귀국일
> - 기타 안내 사항 (세미패키지 QR 등)
> ```
> 발송 타이밍: **출국일 1주일 전** 기준

### 🔄 영문명 오류 수정이 필요한 경우 (에어마카오)
> 항공권 발급 후 영문명 오류 발견 시 에어마카오 담당자에게 즉시 연락한다.

```
<영문명 변경>

[기존] HONG/GILDON
항공권번호: 675XXXXXXXXX1
=> [정정] HONG/GILDONG

해당건도 확인 부탁드리겠습니다.
```

> ⚠️ 영문명 변경은 수수료 발생 가능 → 발권 전 단계에서 처음부터 정확하게 입력.

## ⚠️ 주의사항
> [!warning] 정보 매칭 오류 = 현장 사고
> - **고객별 매칭 오류 시 잘못된 정보 발송 → 대형 CS.** 다른 고객 항공권 번호 발송 시 현장 탑승/체크인 사고로 직결.
> - 발송 전 **이름·여정·인원·확정번호(항공·호텔)**를 건별로 대조 검수한다.
> - 에어마카오 = 항공권 번호 / 에어부산 = E티켓 — **형식 혼동 금지**. 고객이 그대로 제시·확인할 수 있는 형태로 정확히 적는다.

- **중간확정** 문자(72시간 후 처리 단계)와 헷갈리지 말 것 — 이건 **최종** 확정.
- 발송 완료 후 반드시 ○ 체크 — **누락 방지**.
- **한 건이라도 미발송이 남으면 공구 종료로 처리하지 않는다.**

> [!tip] ⚙️ 보완(확인필요)
> 아래는 신 흐름 신규 항목으로 사내 실제 운영과 맞는지 확정 필요. 확정되면 ⚙️ 떼고 본문에 고정.
> - "공구 종료" 처리의 정확한 정의(어떤 시트/상태값으로 닫는지).
> - 발송 채널(문자/알림톡 등)과 발송 기록·보관 위치.
