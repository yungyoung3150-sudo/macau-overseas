# 📌 STEP-01: 일정·답사 확정 & 캘린더 등록
> 이번 공구의 **답사(촬영)일 · 오픈일 · 마감일**을 확정하고, 팀 전체가 보는 캘린더에 등록해 모든 후속 일정의 기준선(역산 기준)을 만든다.

---
## 👤 담당자
| 역할 | 담당자 |
|------|--------|
| 선행(KOL 설득·일정 조율) | 고대표님 · 김대표님 (대표 주도) |
| 메인 (일정 확인·캘린더 등록) | 김용성 · 정민님 |

## 📋 절차

**선행 전제 (대표님 주도 — 내 역할 없음)**
- KOL 발굴·컨택·마카오 공구 제안·설득(시딩 포함)은 100% 대표님 주도다. 이 단계의 시작점은 "공구 건이 확정되고 대표님이 KOL과 시딩 일정을 조율한 시점"이다.
- KOL 확정·일정 공유가 단톡방에 올라오면 즉시 아래 본 절차로 진입한다.

**본 절차**
1. 대표님이 KOL과 조율한 **답사(=촬영) 기간**을 단톡방에서 확인 — 인플 일정 + 현지(마카오) 가능일이 교차 확인된 날짜.
2. 공구 **오픈일 / 마감일** 확정. 오픈 D-day가 셋업·홍보·확정 일정 전체의 역산 기준이 되므로 정확한 시·분까지 확인한다.
3. 확정한 일정(답사 · 오픈 · 마감)을 **캘린더에 등록** → 아래 `## 주의사항`의 ⚙️ 캘린더 표준 등록 항목 참고.
4. 등록 후 담당 · 대표 · 인플에게 일정 공유.
5. KOL 정보 정리 시작 — **채널 링크 · 팔로워 수 · 인원 · 숙박 기간**. (이 정리물은 [[STEP-03|STEP-03]]에서 항공사/호텔 각 담당자에게 전달할 재료가 된다.)

## ⚠️ 주의사항
> [!warning] 선행 단계는 대표님 영역
> KOL 발굴·제안·설득은 100% 대표님 주도 — 내가 개입할 단계가 아니다. 일정이 단톡방에 공유되는 즉시 [[STEP-02|STEP-02]] / [[STEP-03|STEP-03]] 재료 준비로 전환한다.

- 일정 확인 즉시 후속 단계 재료 준비를 시작한다. 항공사(에어마카오 / 에어부산)·호텔(갤럭시 / 리스보아) 각 담당자에게 전달할 **KOL 정보를 미리 정리**해 둔다.

> [!warning] ⚙️ 보완(확인필요) — 캘린더 등록 SOP
> 사내에서 어떤 캘린더(구글 / 네이버 / 사내 도구)를 정본으로 쓰는지 **확정 필요**. 다만 아래 **표준 등록 항목**을 정해두면 어느 툴이든 동일하게 적용된다.
> - 일정 제목 규칙: `[공구] {상품명} / {인플}` 예) `[공구] 갤럭시마카오 / 리얼커플`
> - 필수 필드: 답사기간 · 오픈 일시(정확한 시·분) · 마감 일시 · 담당자 · 인플 · 링크(노션)
> - 마일스톤 별도 표시: D-3(홍보 피드) · D-day(오픈) · 오픈+1일(분석) · +72h(확정 시작)
> - 알림: 오픈 1일 전·1시간 전 / 마감 1일 전
>
> 👉 **할 일**: 사내 캘린더 1개 확정 + 위 항목으로 반복 일정 템플릿 한 번 만들어 저장.
