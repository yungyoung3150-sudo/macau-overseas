# 📌 STEP-27: 항공 PNR(APIS) 생성 & 항공사 공유
> 여권·여정이 확정된 건만 추려 에어마카오·에어부산 [[PNR|PNR]]([[APIS|APIS]])을 생성·항공사에 공유하고, 구글 시트에 기록한다. 동시에 인플에 완료율 등 진행상황을 상시 공유한다. 오기입 시 금전 패널티.

---
## 👤 담당자
| 역할 | 담당자 |
|------|--------|
| 메인 | 김용성 |

## 📋 절차

> **선행**: [[STEP-26|STEP-26]](여권정보 미입력 문자) 회신분 유입 + [[STEP-24|STEP-24]](72시간 후 해피콜·자동 확정)에서 확정된 건이 모인 상태에서 시작.

### 0. 확정 건만 추출
1. **여권/여정이 모두 확정된 건만** 추출 (미확정·여권 미수신 건 제외)
   - 미확정·누락 건은 섞지 말고 [[STEP-26|STEP-26]](여권정보 미입력 문자) 흐름으로 다시 수집

### 에어마카오 PNR (APIS) 생성
2. 에어마카오 담당자에게 여권 명단 전달 요청 (→ [[에어마카오 담당자 문의|에어마카오 담당자 문의]])
3. APIS 시스템에서 생성 (Advanced Passenger Information System)
   - 여권 정보 없을 때: 임시번호 **`m0000000`** 입력
   - 유아(인펀트, Infant) 포함 시: 해당 승객 숫자에서 **INF로 수정 후 저장** (→ [[인펀트 APIS|인펀트 APIS]])
4. 생성 완료 후 구글 시트에 PNR 입력 + **세모(△) 표시**

### 에어부산 PNR 생성
5. 에어부산 전용 시스템 직접 입력
   - 입력 항목: 영문 성/이름, 생년월일, 성별, 여권 번호, 만료일
6. 구글 시트에 PNR 입력 + **세모(△) 표시**

### 더블체크
7. 영문명·생년월일·여권번호 전체 재확인 (혼자 하지 말고 동료 교차 확인)

### 항공사 공유 & 기록
8. 생성한 PNR(APIS)을 **항공사에 공유** (에어마카오=담당자 톡방 / 에어부산=단톡방 — 채널은 → [[에어마카오 담당자 문의|에어마카오 담당자 문의]] 참조)
9. 제작·공유 상태를 건별 기록 (제작완료 / 공유완료 / 미확정 보류)

### 인플 진행상황 공유 (상시)
10. 인플에 **완료율 등 진행상황을 상시 공유** ([[세일즈방|세일즈방]] 활용)
    - ⚙️ 보완(확인필요): 인플 진행상황 공유 채널·주기·양식(어디서 어떤 양식으로 완료율을 전달하는지) 사내 운영 기준 확정 필요

## 🔴 영문명 변경이 필요한 경우 (에어마카오)

> 이미 발권된 항공권의 영문명 오류 수정 — 에어마카오 담당자에게 아래 형식으로 요청 (→ [[여권 영문명 변경 (에어마카오)|여권 영문명 변경]])

```
<영문명 변경>

[현재 이름] KIM/CHULSU
항공권번호: 675XXXXXXXXX2
=> [정정 이름] KIM/CHEOLSU

해당건 확인 부탁드리겠습니다.
```

> ⚠️ 발권 후 영문명 변경은 수수료 발생 가능 → 처음부터 정확하게 입력하는 게 최우선

---

## 👶 인펀트 포함 시 처리 (에어마카오 APIS)
- 인펀트(만 2세 미만)가 있는 경우 → 해당 승객 수에서 **INF로 변경 후 저장**
- 인펀트는 좌석 없이 보호자 무릎 탑승 → PNR은 보호자에 연결

---

## ⚠️ 주의사항

> [!warning] 여권·여정 미확정 건은 제외
> APIS는 여권정보가 정확해야 항공사 제출이 유효하다. 미확정·여권 미수신 건을 섞어 제작하면 정정·재제출이 발생한다. **확정 건만** 추려서 제작하고, 누락·오류 건은 [[STEP-26|STEP-26]](여권정보 미입력 문자) 흐름으로 다시 수집한다.

- **🔴 오기입 시 변경 수수료 또는 전액 패널티 발생 → 무조건 더블체크**
- 에어마카오와 에어부산 PNR 생성 방법이 다름 — 혼동 금지
- 공구 종료 이후 **1주일 내** 완료 필수 (Deadline)
- 세모(△) 표시는 PNR 생성 완료 신호 — 빠트리면 추적 불가
