# 📌 STEP-02: 캘린더 확인 (아침 스크럼 전)
> 매일 업무 시작 전 캘린더를 열어 오늘·이번 주 마일스톤을 확인하고, 아침 스크럼에서 보고할 한 줄을 정리한다. 1회성이 아니라 매일 반복하는 습관.

---
## 👤 담당자
| 역할 | 담당자 |
|------|--------|
| 메인 | 김용성 |
| 확인 | 정민님 |

## 📋 절차
1. **매일 출근 직후, 아침 스크럼 전**에 캘린더를 연다.
2. **오늘 마일스톤** 확인 — 오픈 / 마감 / 답사 / 확정 등 임박 건.
3. **D-3 / D-day / 오픈+1 / +72h** 도래 건 체크.
   - 72h(72시간)는 [[STEP-24|STEP-24]] 해피콜·자동확정 트리거이므로 도래 여부를 매일 본다.
4. 도래한 마일스톤에 따라 해당 STEP으로 분기(예: 오픈 D-3 → [[STEP-18|STEP-18]] 홍보 피드 확인, 72h 도래 → [[STEP-24|STEP-24]] 해피콜).
5. 시딩 일정이 새로 확정됐다면 **KOL 정보 정리**를 함께 점검 — 채널 링크, 팔로워 수, 인원, 숙박 기간. (항공사·호텔 각 담당자 전달용 재료, [[STEP-03|STEP-03]] 준비)
6. **스크럼용 한 줄 정리**: "진행중 공구 N건, 오늘 핵심: ___" → 데일리노트 인박스에 기록.

## ⚠️ 주의사항
> [!warning] 임박 건은 즉시 분기
> - +72h 도래 건을 놓치면 [[STEP-24|STEP-24]] 자동확정/해피콜 타이밍이 밀려 CS·취소수수료 리스크로 직결된다. 매일 반드시 확인.
> - 오픈 D-3가 도래한 공구는 그날 [[STEP-18|STEP-18]] 홍보 피드 점검으로 넘어간다.
- KOL 정보(채널·팔로워·인원·숙박 기간)는 시딩 일정 확정 즉시 정리 시작 — [[STEP-03|STEP-03]] 항공사·호텔 전달이 지연되지 않도록.
- ⚙️ 보완(확인필요): 사내에서 쓰는 캘린더 툴(구글 / 네이버 / 사내 도구)이 무엇인지 확정되면 확인 동선을 이 노트에 고정한다. ([[STEP-01|STEP-01]] 일정·답사 확정·캘린더 등록과 동일 항목)
