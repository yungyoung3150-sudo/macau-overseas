1. 정글 부킹에 들어감 
2. 해당 환불 원하는 고객 조회
3. 구글 스프레드 시트 ([내부 링크 삭제]) 결제 취소 시트 오픈
4. 맨 아래 칸에 입력 준비
5. 정글 부킹에서 고객 주문 내역 상세보기 클릭
6. 기본 정보 스프레드 시트에서 입력 된거 참고 해서 복붙
7. 환불금액에 환불 들어가는 금액 입력
8. 결제 ID 까지 복붙
9. 다 됐으면 정글 부킹 고객 주문 내역 취소 하기 누르기
10. 전액 환불 체크 풀기
11. 해당 환불 금액 입력 
12. 완료 누르면 검은색 글씨고 해당 환불 금액 뜸

# 중요 포인트
- 검은색 글씨로 환불 금액 나오기 위해서는 고객님 결제일 기준 14일 이후만 진행이 가능
- 고객님이 부분 환불 요청 했는데 14일 전이면 전액 환불 들어가야 하기 때문에 나중에 부분환불로 안내 후 14일 지나고 부분 환불 진행
