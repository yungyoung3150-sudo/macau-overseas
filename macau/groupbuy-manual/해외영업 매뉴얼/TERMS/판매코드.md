# 📖 판매코드
> 이번 공구 상품을 식별하는 판매 코드. 코드 ↔ 상품·가격·링크 연결을 **실제 클릭 테스트로 검증한 뒤** 인플에게 전달한다.

---
## 상세 설명
[[상점|상점]]에 등록한 이번 공구 상품에 부여되는 식별 코드다. 코드 하나가 특정 상품·가격·[[판매기간 정리|판매]] 링크에 1:1로 맞물려야 하며, 생성만으로 끝나지 않고 코드 ↔ 상품·가격·링크 매핑이 정상인지, **실제 클릭 테스트로 정상 판매 페이지가 열리고 표시 가격이 요금표 확정가와 같은지** 눈으로 확인한 뒤 [[KOL|인플]]에게 넘긴다.

코드 연결 오류는 오픈 직후 매출 손실로 곧장 이어지므로 전달 전 검증이 핵심이다. 이전 공구의 코드·링크를 그대로 재사용하면 이전 건으로 연결되는 사고가 나므로, 이번 공구 [[상점|상점]] 기준으로 새로 발급한다.

⚙️ 보완(확인필요): 코드의 형식·자릿수, 발급 위치·권한(상점 플랫폼이 Wix인지 자사몰인지, 선임 셋업인지 본인 작업인지), 생성 절차의 세부는 사내 확정 후 보강.
