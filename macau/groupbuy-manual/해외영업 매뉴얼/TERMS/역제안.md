# 📖 역제안
> KOL이 마카오 시딩 귀국 후, 팔로워 관심도 기반으로 어떤 상품으로 공구를 진행할지 함께 결정하는 프로세스

---
## 상세 설명
- 우리가 일방적으로 상품 구성을 정하는 게 아니라 KOL의 의견을 반영
- KOL이 가장 팔릴 것 같은 상품을 제안 → 우리가 데이터(인스타 피드 반응)로 검증 → 최종 결정

## 핵심 원칙
- **인스타 피드·릴스 반응 확인 필수** — 기존 마카오 콘텐츠 팔로워 반응 분석
- '예스트래블이 해줘' 방식 경계:
  - KOL이 구성을 맡으면 안 팔릴 때 우리에게 책임 전가 가능
  - **우리가 데이터 기반 제안 → KOL 동의 구조**로 진행

## 잘못된 역제안 사례
> KOL이 버스 투어로 홍보했는데 → 우리가 디즈니 패키지로 구성
> → 고객 반응 無, 인플 반응 無 → 딜 실패
