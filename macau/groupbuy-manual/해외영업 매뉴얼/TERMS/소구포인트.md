# 📖 소구포인트 (訴求 Point)
> 고객이 이 상품을 구매해야 하는 이유를 설득력 있게 정리한 홍보 포인트

---
## 상세 설명
- 訴求(소구) = 고객의 욕구·필요에 호소한다는 의미
- KOL이 팔로워에게 상품을 홍보할 때 사용하는 핵심 메시지
- 내가 직접 제작 (김용성 담당)

## 작성 체크리스트
- [ ] 유류세 인상 부담 없음 강조
- [ ] 자유여행 / 세미패키지 선택 가능 여부 (인플마다 다름)
- [ ] 지방 출발 (부산) 여부 명시
- [ ] 객실 크기·호텔 퀄리티 포인트
- [ ] 조식 포함 여부 (→ [[09 참고 자료 창고|호텔별 조식 가격 참고]])
- [ ] 바우처 혜택 (갤럭시: 200MOP 쇼핑 바우처 등)
- [ ] 인펀트(유아) 추가 비용 (→ [[09 참고 자료 창고|인펀트 추가 비용 참고]])
