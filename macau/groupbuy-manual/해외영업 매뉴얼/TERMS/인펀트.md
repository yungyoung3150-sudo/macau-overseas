# 📖 인펀트 (Infant)
> 만 2세 미만 유아. 항공·여행상품에서 별도 요금 체계 적용.

---
## 상세 설명
- 만 2세 미만(생후~만 24개월 미만)
- 항공: 좌석 미배정, 보호자 무릎 탑승 → 별도 저렴한 요금 적용
- 여행상품: 인펀트 추가 비용 발생 (상품마다 다름)

## 실무 포인트
- 소구포인트 제작 시 인펀트 추가 비용 명시 필수
- 예약폼(구글폼) 수집 시 **인펀트 체크 항목** 포함
- PNR 생성 시 인펀트는 보호자 PNR에 연결

## 요금 예시
| 구분 | 기준 |
|------|------|
| 항공 인펀트 | 성인 요금의 10~15% 수준 |
| 호텔 | 대부분 무료 (엑스트라 베드 없으면) |

## 주의
- 만 2세 생일 당일은 차일드(Child) 요금 적용 → 생일 확인 필수
