# 📖 APIS (Advanced Passenger Information System)
> 항공 탑승 전 출입국 당국에 미리 전달하는 승객 여권 정보 시스템

---
## 상세 설명
- 여권 번호, 만료일, 국적, 생년월일, 영문 성명 포함
- 에어마카오의 경우 PNR 생성 시 함께 요구되는 경우 있음
- 오기입 시 탑승 거절 사유 → 패널티

## 수집 항목
| 항목 | 예시 |
|------|------|
| 영문 성명 | HONG GIL DONG |
| 여권 번호 | M12345678 |
| 여권 만료일 | 2030-01-01 |
| 생년월일 | 19900101 |
| 국적 | KOR |

## 주의
- 여권 유효기간 출발일 기준 **6개월 이상** 남아있는지 확인
- 성명 철자 오류 → PNR 이름 불일치 → 탑승 불가
- 민증 뒷자리가 없는 경우 전화로 직접 확인 (→ [[STEP-21|STEP-21]] 보험 가입과 동일 이슈)
