# 📖 공헌이익 (Contribution Margin)
> 총 마진에서 인플루언서 비용 등 변동비를 뺀 실제 기여 이익

---
## 계산 구조
```
공헌이익률 = 총 마진율 - 인플루언서 비용률
현재: 12% - 4% = 목표 8%
현재 실적: 4.7% (목표 달성 필요)
```

## 실무 적용
- 본부장님이 모니터링 데이터 기반으로 계산
- 공헌이익이 8% 이상 나와야 상품 진행 가능
- 마카오 기준: 3천만원 매출 시 마진 약 120만원 (시딩비 못 나오는 수준)

## 회사 목표
- 분기 거래액 70억 달성 시 평균 공헌이익 4% = 2.8억
- 내년 6월까지 거래액 1000억 목표
