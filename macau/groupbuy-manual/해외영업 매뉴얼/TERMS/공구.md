# 📖 공구 (공동구매)
> 인플루언서(KOL)가 팔로워에게 여행상품을 한정 기간·한정 수량으로 판매하는 소셜커머스 방식

---
## 상세 설명
- 공동구매의 줄임말
- 예스트래블의 핵심 매출 구조
- KOL 팔로워 신뢰도를 활용해 단기간 집중 판매

## 공구 구조
```
KOL 피드/스토리 노출 → 링크 클릭 → JBS 예약·결제 → 여권폼 제출
```

## 공구 기간
- 통상 3~5일 (오픈~마감)
- 항공 좌석·호텔 블록 소진 시 조기 마감

## 공구 종류
| 종류 | 설명 |
|------|------|
| 일반 공구 | 첫 오픈 딜 |
| [[앵콜딜\|앵콜딜]] | 재오픈 딜 |
| 데일리딜 | 매일 단건 오픈 (데일리 상품) |

## 등장하는 단계
STEP-01부터 STEP-22까지 전 과정이 하나의 공구 사이클

## 관련 용어
- [[KOL\|KOL]] — 공구의 마케팅 채널
- [[JBS\|JBS]] — 공구 예약 시스템
- [[공헌이익\|공헌이익]] — 공구 수익성 지표
