# 📖 PNR (Passenger Name Record)
> 항공사 예약 시스템에서 승객의 예약을 식별하는 고유 예약 코드 (6자리 영숫자)

---
## 상세 설명
- 예: `ABC123`
- 에어마카오·에어부산 각각 별도 PNR 시스템 운영
- PNR 생성 = 항공 예약 확정

## 에어마카오 PNR 생성
- 에어마카오 담당자에게 여권 명단 전달 → 담당자가 생성
- 구글시트에 PNR 기입 후 **반드시 세모(△) 표시**
- 전달 후 48시간 내 발권 필요 (미발권 시 자동 취소 리스크)

## 에어부산 PNR 생성
- 에어부산 전용 시스템 직접 입력
- 입력 항목: 영문 성/이름, 생년월일, 성별

## ⚠️ 가장 중요한 주의사항
> **오기입 시 변경 수수료 또는 전액 패널티 발생**
- 여권 영문명 철자 확인 3회 이상
- 생년월일 오입력 주의
- 더블체크 필수 — **혼자 확인 금지, 반드시 동료와 교차 확인**
