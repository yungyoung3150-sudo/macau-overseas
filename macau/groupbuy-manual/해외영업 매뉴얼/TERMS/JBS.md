# 📖 JBS (Joint Booking System / 공구 예약 페이지)
> 예스트래블에서 공구 오픈 시 고객이 예약·결제하는 예약 시스템 페이지

---
## 상세 설명
- 공구마다 별도의 JBS 페이지 생성
- KOL 피드/스토리에서 고객이 링크를 클릭해 예약 진행
- 예약 완료 시 고객이 여권폼(구글폼) 링크로 이동

## 세팅 항목 (STEP-09)
- [ ] 후킹가 반영
- [ ] 상품 옵션 구성 (세미패키지 유무, 객실 타입)
- [ ] 출발일 / 귀국일 설정
- [ ] 여권폼 링크 연결 (→ [[구글폼|구글폼]])
- [ ] 예약 메시지 문구 수정 (→ [[STEP-12|STEP-12]])

## 주의
- 세팅 전 반드시 항공 모객현황·호텔 SCM 가용 객실 확인 (STEP-10)
- 오픈 직후 예약 폭주 대비 → CS 채널 사전 준비

## 관련 용어
- [[공구|공구]] — JBS가 운영되는 공구 구조 전체
- [[SCM|SCM]] — 호텔 객실 가용 확인
