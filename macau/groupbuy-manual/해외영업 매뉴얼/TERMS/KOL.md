# 📖 KOL (Key Opinion Leader)
> 마케팅 파트너로서 인스타 팔로워에게 상품을 홍보하는 인플루언서

---
## 상세 설명
- Key Opinion Leader의 약자
- 예스트래블에서는 인스타그램 팔로워 보유 인플루언서
- 마카오 공구의 핵심 마케팅 채널 — KOL 없이 공구 없음

## 등급 기준 (팔로워)
| 등급 | 규모 |
|------|------|
| Mega | 100만+ |
| — | 60만 / 50만 / 30만 / 20만 |

## 실무 포인트
- 팔로워 수와 판매력은 반드시 비례하지 않음
- **인스타 피드 반응 확인이 상품 매칭의 핵심** (STEP-06)
- 인플마다 세미패키지 진행 여부 다름 → 반드시 확인
