# 해외 브랜드 파트너 정리

> 2026-03-06 팀장님 미팅에서 정리한 내용

---

## 🏨 Hotel (마카오)

### 1. 갤럭시 리조트 (독점 계약)

#### Andaz (안다즈)
- **특징:** 신축·고급 5성 / 빈 객실 물량 ↓

**고객이 안다즈를 원한다면
1. 먼저 갤럭시 담당자 분께 요청 - 담당자분은 최대한 추가 제공 할 수 있는 수량 파악하고 되면 된다. 없으면 없다. 이야기 할거임

**안다즈 안될 경우 고객이 할 수 있는 2가지:**
1. 날짜를 바꾼다
2. 호텔을 바꾼다 (날짜 바꿔도 안되는 경우)

> ☆ **Important:  최대한 고객이 요청한 거는 확인을 꼭 해준다.**

**투숙 규정 (안다즈):**
- 킹 베드 (고층 / 저층) 
- 트윈 베드 (고층 / 저층)
>고층/저층 구분 기준 : 고층은 8층 이상 저층은 최하층~7층까지

**투숙 인원 규정 (안다즈):**

| 구성          | 처리 방법                                        |
| ----------- | -------------------------------------------- |
| 성인 3명 이상    | Extra Bed 나옴 → 추가 비용 발생(원하지 않는다고 발생 안되는거 아님) |
| 성인 2 + 소인 2 | 추가 요금 X                                      |

> ⚠️ Extra Bed 나오면 고객에게 추가 요금 공지 + 예약 확정 후 갤럭시 어드민으로 이메일 작성 까지 해야 함 (상세 내용 아래 설명 참고)

**예약 시 주의사항:**
- 성인 3으로 예약 **불가**
- 성인 2 + 소인 1로 조회 후 예약 진행 → 호텔측 어드민에 이메일 발송 (Extra Bed request)
- Andaz도 Admin 있음
- 단, 우리가 별도 투숙 고객의 **취소 및 변경 불가** → **예약만 넣을 수 있음**
==특가 조건임== 
---

#### Broadway (브로드웨이)
- **특징:** 상대적으로 구축 → 가성비 호텔 4~5성 / Andaz보다 객실 물량 ↑

**투숙 규정 (브로드웨이):**
- 킹 베드 (시티뷰 / 리버뷰)
- 트윈 베드 (시티뷰 / 리버뷰)

**투숙 인원 규정 (브로드웨이):**

| 구성          | 처리 방법                             |
| ----------- | --------------------------------- |
| 성인 2 + 소인 1 | MAX - 건물이 작아서 Extra Bed 들어갈 곳이 없음 |
| 성인 3명 일시    | 객실 2개 해야됨                         |

> ⚠️ 고객분들에게 이 점 꼭 고려해야 함
> Ex) 고객이 성인 5분이시면 객실

### 2. 그랜드 리스보아 팰리스 (신규 계약)
- 이번 Influencer 여행과 공구 계획
- **특징:** 가격이 매우 높음 (따라서 Margin 높게 잡힐 수 밖에 없음) / 매출 기대 큼

> 🔴 **신규 계약 / 최저가 모니터링 무조건 신경써야 함** (인플루언서에게 컴플레인 가지 않게)

## 🌏 CNU 여행사 (해외 파트너)

- **특징:** 동남아 쪽 상품 중심 (거의 **베트남**)
- CNU 측에서 상품 관련해서 넘김 (량과 함께)

**우리가 해야 할 일:**
- 인플루언서 매칭은 대표님이 보통 공냄
- 최저가 모니터링 및 구성 모니터링 **continuously**

**Cancel Policy:**
- 우리 룰 따라감
- 기간별 취약금 기준

> **Important point:** 환전 단가 있어가 Extra
> → meaning: 환율 변동이 있으면 가격이 높아짐 (high price)
