# 국내 브랜드 파트너 정리

> 2026-03-06 팀장님 미팅에서 정리한 내용

---

## 1군

### 🏨 SONO (주요 클라이언트)
- **국내 No.1 호텔·리조트**
- 특징: 거점 많음 / 4개 테마브랜드, 18 사업명 (소호초 포함)
- 대체로 "언제 얼마가" 기준 → SONO 자체 Admin 담당자가 다름

**공동 진행 브랜드:**
- **금호** — SONO와 시스템 거의 동일
- **컨시던** — 최근 계약 완료 / 각 지점별 소통 / 특이: 건산중 × → 스프레드시트 공유 방식

---

### 📋 SONO 공구 단계 (절차)

| 단계 | 내용 |
|------|------|
| 1 | 브랜드 검토 |
| 2 | 인플루언서 섭외 (리겔 고려 방식) |
| 3 | 제안서 검토 — 먼저 제안서 보내고, 담당자가 1명1명 판매 담당으로 배분 |
| 4 | 담사 (담당자 협의) |
| 5 | 프로모션 구체화 및 확정 → 최초 확정 |
| 6 | 셋팅 — 공구 / 할인 담당 / 카카오 프로모션 등록 |
| 7 | **Janda 생성** + 날짜·재고 코드 세팅 → 해당 날짜 오픈 준비 |
| 8 | 공구 날짜 오면 오픈 |
| 9 | CS / 취소 처리 |

---

### ⚠️ SONO CS & 취소 처리

- SONO는 **자체 Admin 필요** (예약/처리가 Admin 안에서 이뤄짐)
- **SONO Admin → 예약확정 → 고객에게 확정 문의 불통 시 처리**

> ✱ 예약확정 위한 규정 반드시 숙지!

**취소 시 주의:**
- 변경 없는 점 기재에도 처매들이 모두 전 기간에만 1박 단위 신뢰 가능
- 취소 후 나온 기간은 변경 가능

**Ex) SONO 계약 기간 내 고객이 취소 요청 시:**
1. 일단 SONO Admin 안에서 직접 취소 진행
2. 그 건의 고객에게 → 최신 처리금 과제 확인 (이게 먼저)

> 특이점: 고객 건강욕구 / 기관 참여의 이런 경우 → 여성이면요 위력 써서 성인이 들어가도 한다.
> SONO의 각 처 → SONO Admin으로 신청 (포총 처리 넘기 권한)
> **(CS 시스템 들어가면 나도 할 줄 알아야 함)**
