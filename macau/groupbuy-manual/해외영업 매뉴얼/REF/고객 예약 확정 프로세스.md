## 📋 전체 흐름 (한눈에)

```
예약에 필요한 사이트 준비 → 고객명단에서 일정확인 → 항공권 구매 가능여부 체크 → 호텔 객실 구매 가능여부 체크  → 호텔 가능하면 바로 Reserve 누름 → **총 결제 금액 공구 시트 금액과 일치하는지 확인** → 결제 카드 등록 → 고객 개인정보 국적 먼저 수정 → 고객 명단(해피콜 시트)확인 → 성,이름 복사 붙이기 → 호텔 예약확정 → 공구스프래드 시트에서 상태에 해피콜 완료 체크
```

[내부 시스템 주소 삭제]

>	카드 종류에 MA 입력

>	[카드 유효기간] 복붙
>	KOISTROY 복붙

## 1️⃣ 예약에 필요한 사이트 준비

- 마카오 호텔 부킹 사이트 ([내부 시스템 주소 삭제])
- 해당 공구 스프레드 시트
- 에어마카오 좌석 수량 ([내부 링크 삭제])
- 마카오 해피콜 시트 ([내부 링크 삭제])

---

## 2️⃣ 고객 명단에서 일정 확인

- 출국일,입국일 확인 ==**2박 3일인지, 3박4일인지 확인**==  → **수량 확인**
- 성인 3명의 경우 조회 안됨 성인 2 + 소인 1로 예약 하고 추후 성인 3명이라고 호텔 측에 이야기 해야됨

---

## 3️⃣ 에어마카오 좌적 수 스프레드 확인




---

## 4️⃣ 호텔 객실 구매 가능 여부 체크

- New Booking에 들어가서 Room Availablity 에서 선택 사항 선택
- 성인 2명 이상이면 조회 불가능 → 성인 2명으로 하고 객실 수를 올려야 됨
- 고객이 주문 넣은 객실 타입 예약 가능 여부 확인 (==조식포함과 미포함 있으니 꼭 확인 해야함==) **가격차이 많이 남**
- 예약 가능하면 Reserve 버튼 누름
==**Important point**== : 고객의 특수 요청사항 확인 (예시 : 예약 확정 전에 전화 꼭 주세요.등등 )

---

## 5️⃣ 호텔 예약 대금 지불 프로세스

- ==객실 금액 MOP(마카오 달러)와 공구 진행 스프레드에 있는 결제 금액 일치 하는지 확인==
- 일치 하면 고객 국적 KR로 변경
- 마카오 해피콜 스프레드에서 개인정보 조회 성,이름 복붙
- 결제 및 호텔 예약 확정


---

## 6️⃣ 최종 확정 처리 프로세스

- 공구 스프레드 들어가서 상태 버튼을 해피콜 완료로 변경
- 이렇게 하면 최종 확정 처리 완료
