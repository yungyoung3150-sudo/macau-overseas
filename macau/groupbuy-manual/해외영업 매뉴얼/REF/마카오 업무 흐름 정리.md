9. 고객 확정 문자

## 에어마카오 APIS(PNR) 생성 방법

> APIS = Advanced Passenger Information System (사전 승객 정보 시스템)

- **여권 정보 없을 때** → 임시번호 `m0000000` 입력
- **유아(Infant) 포함 시** → 해당 승객 숫자에서 **INF로 수정 후 저장**
