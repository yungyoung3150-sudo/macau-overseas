[내부 시스템 주소 삭제]
트래블로버 B2B 사이트

1. 여행자 보험 가입하고 상단 클릭
2. 여행정보 입력 -> 신청하는 분  담당자 : 김민경 -> 연락처 노터치 -> 이메일 : ot@ yestravel.co.kr
3. 여행자 보험 정보 
	- 보험 종류 = 단기해외여행 클릭
	- 여행기간 = 고객 여행 일정 입력
	- 여행 국가 : 마카오
	- 여행 가시는 분에서 명단 붙여넣기 이용
	- 고객 이름, 민증, 영어이름 순으로 복붙 (동행자 포함)
	- 명단 넣은 후 명단 다 선택
4. 여행자 보험 플랜 선택하기 버튼 클릭
5. 맨 왼쪽 오렌지 보험 상품 클릭
6. 여행자보험 계약 확인 그냥 느낀대로 눌러서 패스
7. ==결제 방법 : 가상계좌== + 가입 동의 항목 체크
8. 입금도 노터치 ->입금 은행 : 기업은행
9. 현금 영수증 발행에서 지출 증빙용 선택 -> 발급방법 선택 = 사업자번호 : 315-87-02973  -> 결제 진행
10. 결제 내역 확인
	- (대량이체 샘플 파일은 담당자에게 요청)
	- 입금 은행 복붙
	- 입금계좌번호 복붙
	- 이체금액 복붙
	- 내통장 인쇄 내용에 몇일 출발인지 작성 (예시 : 0410 출발)
11. 이후 보험 가입 스프레드시트 들어가 작성 완료 고객 노란색 색칠 
- [내부 링크 삭제] 스프레드 시트 (보험 가입용)
