# 👋 먼저 읽기 — 이 매뉴얼 여는 법

예스트래블 **해외영업팀 · 마카오 공동구매 실무 매뉴얼**입니다. 공구 한 건을 처음부터 끝까지 도는 **8 PHASE · 30 STEP**을 담았습니다. 이 폴더는 **옵시디언(Obsidian) 볼트**라서, 옵시디언으로 열면 위키링크·그래프·백링크·빠른검색이 다 살아납니다.

## 🚀 여는 순서 (5분)
1. **옵시디언 설치** — https://obsidian.md (무료, Mac/Windows 둘 다).
2. 받은 압축파일(`.zip`)을 **압축 해제**. → `예스트래블 해외영업 매뉴얼` 폴더가 나옵니다.
3. 옵시디언 실행 → **"Open folder as vault"(폴더를 볼트로 열기)** → 위 폴더 선택.
4. "신뢰하시겠습니까(Trust author)" 물으면 **신뢰(Trust)** 선택. → 끝. (별도 플러그인 설치 불필요 — 순정 옵시디언에서 그대로 작동)

## 🧭 사용 팁
- **여기서 시작** → [[🐘 해외영업팀 메뉴얼 허브]] (8 PHASE · 30 STEP 전체 목차)
- **단계 이동**: 본문의 파란 글씨(위키링크) 클릭 — STEP↔STEP, 용어, 참고자료로 바로 점프.
- **빠른 검색**: `Cmd/Ctrl + O` → 노트 이름으로 즉시 이동. `Cmd/Ctrl + Shift + F` → 전체 본문 검색.
- **백링크**: 각 노트 하단/우측에서 "이 노트를 가리키는 곳" 확인.
- **그래프 뷰**: 좌측 그래프 아이콘 → 전체 연결 구조 한눈에.
- **용어가 막히면**: [[📖 용어 인덱스]] 또는 본문 STEP의 "핵심 용어".
