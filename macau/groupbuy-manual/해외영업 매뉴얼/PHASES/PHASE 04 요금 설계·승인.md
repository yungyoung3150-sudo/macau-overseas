# 📊 PHASE 04 요금 설계·승인
#요금설계 #최저가모니터링 #항공모니터링 #호텔모니터링 #요금표 #공헌이익 #후킹가

> [[STEP-07|STEP-07]]에서 확정된 상품 구성 위에, 시장 [[최저가 모니터링|최저가 모니터링]]으로 기준선을 잡고 → 원가·마진을 얹어 요금표 초안을 만들고 → 본부장님 [[공헌이익|공헌이익]] 계산·대표 컨펌을 거쳐 → 컨펌된 **최종 요금표 한 버전만** 인플에게 전달하는 PHASE.

---

## 1. 전체 흐름
```
[STEP-07 상품 구성 확정]
        ↓
STEP-08  최저가 모니터링 (항공 + 호텔)
   · 네이버 항공권·트립닷컴·구글 호텔 / 기존 수집 시트 읽기
   · 수화물 포함 "최종가"로 비교, 가드레일 판정(인당 차이)
        ↓  (최신 정보 업데이트 필요하면 완료까지 딜레이 가능)
STEP-09  요금 측정 (초안 작성)
   · 차액 계산기 구글 시트에 원가 정리 → 마진(공헌이익) 얹어 초안
        ↓
STEP-10  요금 대표 컨펌 (공헌이익)
   · 본부장님께 슛 → 공헌이익 계산 → 요금표 수령 → 대표 컨펌
        ↓
STEP-11  요금표 인플 전달
   · 컨펌 최종본 1종(후킹가 포함)만 인플 전달 + 팀장님께 상세페이지 요청
        ↓
[[PHASE 05 판매 셋업|→ PHASE 05 판매 셋업으로]]
```

> [!warning] 수화물 포함 최종가 / 덮어쓰기 금지
> - 외부에 적힌 가격이 낮다고 최종 가격이 낮은 게 아니다. **수화물 가격 포함 X** → 항상 **최종 가격**으로 확인.
> - **에어마카오 시장 최저가는 차액계산기 시트 수식이 이미 정확하므로 다른 소스(구글 등)로 덮어쓰지 말 것.** (예: 8월 2박3일 인당 5~9만 과가격 🟠은 실재하는 신호.)

  - 갤럭시 엔터테인먼트 (그랜드 덱 리조트 — 10월 말까지 운영 예정)
  - 그랜드 리스보아 팰리스
- 관련: [[마카오 패키지 핵심 정보|마카오 패키지 핵심 정보]]

### 🧮 요금표 제작 → 본부장님 전달
#요금표 #차액계산기 #공헌이익

1. 모니터링 완료 → **차액 계산기 구글 시트**에 인원·박수·객실타입별 원가 정리
2. 본부장님한테 슛
3. 본부장님 [[공헌이익|공헌이익]] 계산 완료(총 마진 − 인플 비용) → 요금표 수령 → 대표 컨펌
4. 컨펌받은 최종 요금표 기반으로 [[STEP-11|STEP-11]] 인플 전달 → [[PHASE 05 판매 셋업]] 진행

### 🚦 가드레일 (1차 목적)
- 1차 목적은 완벽한 가격 매칭이 아니라 **컴플레인 가드레일**(고객이 더 싼 가격을 발견해 항의하는 상황 방지)이다.
- **비대칭** 판단: 우리가 시장보다 **비싼 쪽**만 문제다. 인당 차이 기준 — 안전 `<5만` / 주의 `5~10만` / 경보 `≥10만`.
- 시장 데이터가 없는 구간은 "안전"으로 단정하지 말 것 → **수동 확인** 대상.

### ⚠️ 컨펌·전달 관문
- 대표·본부장 컨펌 **전**에는 인플·외부에 요금을 공유하지 않는다. 초안과 최종본을 명확히 구분.
- [[STEP-11|STEP-11]]에는 컨펌받은 **최종본 1종만** 나가게 한다(후킹가 포함). 미컨펌본이 새면 인플이 잘못된 가격으로 홍보 → CS·신뢰 문제.

> [!tip] ⚙️ 보완(확인필요)
> 사내 요금표 양식·원가 항목 정의(어디까지 net 포함)·기준 [[공헌이익|공헌이익]](이 선 이상이어야 통과)은 백업 원본에 수치 근거가 없다. 본부장·대표님께 한 번 배워 [[공헌이익|공헌이익]] 용어 노트에 템플릿으로 고정하면 컨펌 왕복이 줄어든다. (임의 수치 생성 금지)
