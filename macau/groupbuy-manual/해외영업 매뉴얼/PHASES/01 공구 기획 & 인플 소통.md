## 2. 인플루언서 매칭 기준
#인플루언서매칭 #피드분석 #타겟분석

> ⚠️ **핵심 원칙:** 인플의 인스타 피드를 직접 확인해서 현재 어떤 콘텐츠를 올리는지, 팔로워 반응은 어떤지 파악 후 상품을 매칭한다.
> 안 갔다가 온 걸 주면 홍보가 안 되므로 간단한 문제.

| 체크 항목 | 확인 방법 |
|-----------|----------|
| 최근 마카오 홍보 여부 | 인스타 피드 직접 확인 |
| 팔로워 반응 (좋아요·댓글) | 게시물 반응 확인 |
| 가족형 / 무자녀 / 커플 | 피드 콘텐츠 유형 파악 |
| 지방 출발 고객 비중 | 댓글·DM 확인 |

### 인플루언서 등급 (참고)
#메가인플 #인플등급

| 등급 | 팔로워 규모 |
|------|------------|
| Mega | 100만+ |
| — | 60만 |
| — | 50만 |
| — | 30만 |
| — | 20만 |

> 📌 팔로워 수·판매력 관계 없이 일단 다 맞춰준다 (최대한 맞춰준다)
> 📌 인플마다 세미패키지 진행 여부 다름 — 반드시 확인
