# 🧩 PHASE 03 상품 구성·컨설팅
#상품구성 #컨설팅 #역제안 #소구포인트 #노션 #SoT

> KOL이 시딩 촬영을 마치고 귀국한 직후 단계. 답사 결과와 KOL 인스타 피드 반응을 근거로 '팔리는 패키지'를 함께 설계하고, 합의된 최종 구성을 **최종 구성 노션** 하나로 문서화한다. 이 노션이 이후 요금·상세페이지·CS 전 단계의 단일 사실 원본(SoT)이 된다.

---

## 1. 전체 흐름
```
KOL 귀국 확인 후 컨택
    ↓
기본 노션 중 팔로워 관심도 높을 상품 확인 요청
    ↓
KOL 기존 마카오 콘텐츠(인스타 피드·릴스) 반응 직접 확인  ← 모든 구성의 출발점
    ↓
데이터 기반 상품 구성 초안 제안 → KOL 피드백 → 역제안 (1~2회 반복)
    ↓
최종 구성 합의 (KOL 동의)
    ↓
최종 구성 노션 작성 (호텔/객실·박수·항공·포함/불포함·옵션·유의사항)
    ↓
소구포인트 초안 정리 + 대표님·인플 최종 확인
    ↓
최종 구성 노션 URL = SoT → [[PHASE 04 요금 설계·승인|→ 요금 설계·승인]]
```

> [!tip] 컨설팅 = 단순 전달이 아니다
> 시장가 / 원가 / [[공헌이익|공헌이익]] 감각을 가지고 **"팔릴지 + 남을지"를 같이** 본다. 다만 **요금 자체는 이 PHASE에서 확정하지 않는다** — 요금 측정·승인은 [[PHASE 04 요금 설계·승인|PHASE 04]]에서 진행한다. 여기서는 "이 구성이 팔리고 남는 방향인지"의 감각만 잡는다.

## 3. 핵심 포인트 / 참고

### ⚠️ 인스타 피드 미확인 후 상품 구성 = 치명적 실수
> KOL이 버스 투어로 홍보했는데 우리가 디즈니 패키지로 구성 → 고객 반응 無, 인플 반응 無 → 딜 실패.
> 반드시 KOL의 실제 마카오 콘텐츠(인스타 피드·릴스) 팔로워 반응을 확인한 뒤 구성한다.

### '예스트래블이 해줘' 방식 경계
- KOL이 구성을 맡으면 안 팔릴 때 책임이 우리에게 전가될 수 있다.
- **우리가 데이터 기반 제안 → KOL 동의** 구조로 진행해 합의 기록을 남긴다.

### 최종 구성 노션 = 사실 원본(SoT)
- 합의된 최종 구성은 노션 하나로 문서화한다. 명시 항목: 호텔/객실 · 박수 · 항공편(NX/BX 등) · 포함/불포함 · 옵션 · 유의사항(수화물 규정·조식가·인펀트가·셔틀·포토스팟 등).
- 이후 요금 설계·상세페이지 제작·CS 응대는 모두 이 노션을 보고 진행한다. **구성이 바뀌면 반드시 노션을 먼저 갱신**하고, 노션을 기준으로 후속 단계를 다시 맞춘다.
- 산출물: **최종 구성 노션 URL** → [[STEP-08|STEP-08]] 이후 모든 단계의 단일 기준.

### 구성 시 살아 있어야 할 '팔리는 포인트' (→ 소구포인트로 연결)
- [[에어텔|에어텔]] / [[세미패키지|세미패키지]] 선택 가능 여부 (인플마다 다름 — 사전 확인)
- 호텔 퀄리티 포인트 — 신축·고급 vs 가성비 선택지
- 워터파크·[[바우처|바우처]] 등 호텔 특전
- 지방 출발(에어부산) 가능 여부
- 유류세 없음 등 가격 메리트
- [[인펀트|인펀트]] 추가 비용 등 사전 고지 항목

> [!note] 요금·후킹가는 이 PHASE에서 확정하지 않음
> [[후킹가|후킹가]]·[[상세페이지|상세페이지]] 준비 완료 시점은 KOL에게 미리 안내하되, 실제 후킹가 산출은 [[PHASE 04 요금 설계·승인|PHASE 04]]([[STEP-08|STEP-08]]~[[STEP-11|STEP-11]])에서 진행한다.
