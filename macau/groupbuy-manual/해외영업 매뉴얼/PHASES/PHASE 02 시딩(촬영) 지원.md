# 🎬 PHASE 02 시딩(촬영) 지원
#시딩 #KOL #바우처 #촬영 #답사 #에어마카오 #갤럭시 #리스보아

> KOL 시딩 일정에 맞춰 항공·호텔 가능 여부를 확인하고 [[바우처|바우처]]를 전달, 기본 상품 [[상세페이지|노션]]을 공유해 촬영 구성을 맞춘 뒤, 답사 전·중·후로 인플 컨디션을 챙겨 촬영을 무사히 끝낸다.

---

## 1. 전체 흐름
```
KOL 시딩 일정 공유 (보통 대표님이 주심)
    ↓
[STEP-03] 채널별 시딩 항공·호텔 가능 확인 → 바우처 수령·검증 → KOL 전달
    ├─ 에어마카오 → 에어마카오 담당자 톡방
    ├─ 에어부산  → 에어부산 단톡방
    ├─ 갤럭시    → 갤럭시 담당자님
    └─ 리스보아  → 리스보아 담당 이사님 (특전 구성 완료 후 수령)
    ↓
[STEP-04] 기본 상품 노션 공유 → "촬영에 담고 싶은 구성" 확인 → 메모 정리
    ↓
[STEP-05] 답사 전·중·후 컨디션·진행 체크 → KOL 마카오 촬영·귀국
    ↓
[[PHASE 03 상품 구성·컨설팅|→ 제안·역제안 컨설팅]]
```

---

## 3. 핵심 포인트 / 참고

### 🎯 시딩 요청 대상 (채널별)
| 채널 | 전달 경로 | 담당 |
|------|----------|------|
| 에어마카오 | 에어마카오 담당자 톡방 | — |
| 에어부산 | 에어부산 단톡방 | — |
| 갤럭시 (호텔) | 갤럭시 담당자님에게 전달 | 갤럭시 담당자님 |
| 리스보아 | 리스보아 담당 이사님 (특전 직접 구성) | 리스보아 담당 이사님 |

> 메인 담당: 김용성 · 정민님

### ✅ 시딩 요청 시 확인사항
- [ ] 일정 확정 여부 (좌석·요일·박수 규칙)
- [ ] 인원 수
- [ ] 인플루언서 정보 (채널 링크, 팔로워 수)
- [ ] 숙박 기간
- [ ] 항공편 [[바우처|바우처]]
- [ ] 호텔 [[바우처|바우처]]

### ⚠️ 이 PHASE의 핵심 주의사항
> [!warning] 리스보아 바우처는 이사님 확인 전 절대 먼저 보내지 말 것
> 리스보아는 리스보아 담당 이사님이 호텔 특전을 직접 구성해주신다 → 이사님 확인 완료 전 KOL에게 먼저 발송 금지.

> [!warning] 바우처 이름 = 여권 영문과 반드시 일치
> 바우처 이름이 여권 영문과 다르면 발권·체크인이 거부될 수 있다. 여권 영문을 먼저 확보한 뒤 신청하고, 수령한 바우처는 이름·날짜·편명·인원을 한 번 더 대조한다. → [[여권 영문명 변경 (에어마카오)|여권 영문명 변경]]

> [!warning] 인플 응대 톤
> KOL 응대·공유는 **파트너 존중·팩트 기반** 톤을 지킨다. 추가 액티비티/경험 요청은 **무조건 OK 금지** — 가능 여부를 먼저 확인하고 대응한다. 귀국 후 [[PHASE 03 상품 구성·컨설팅|역제안 컨설팅]]은 피드 반응이 식기 전 **빠르게** 진행.

### 📌 시딩이 곧 상품의 출발점
[[STEP-04|STEP-04]]에서 전달하는 **기본 상품 노션**(수화물 규정·호텔 구성·조식가·인펀트가·항공편·셔틀·포토스팟)은 KOL이 마카오를 파악하는 핵심 자료이자, [[PHASE 03 상품 구성·컨설팅|PHASE 03]] [[역제안|역제안]] 컨설팅의 기초가 된다. 누락 없이 전달하고, KOL이 "담고 싶다"고 답한 구성을 메모로 정리해 답사 동선·상품 후보에 반영한다.
