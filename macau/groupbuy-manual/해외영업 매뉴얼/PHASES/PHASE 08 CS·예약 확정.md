# ✅ PHASE 08 CS·예약 확정
#CS #예약확정 #해피콜 #자동확정 #PNR #APIS #여행자보험 #QR발권 #최종확정

> 🔴 **Deadline: 공구 종료 이후 1주일 내 예약 확정 완료** (최종 확정 안내는 출국일 1주일 전 기준)
> ⚠️ 이 PHASE는 대금·여권·발권과 직결된다. **빠르게 하지 말고 천천히, 항상 더블체크.** 오기입·매칭오류는 그대로 금전 패널티·현장 사고로 이어진다.

## 1. 전체 흐름
```
공구 오픈 후 CS 상시 대응 (취소·추가구매·결항·노쇼·인플 질문)   ← STEP-23
        │
        ▼
구매 +72시간 도래 건 추출 → 항공·호텔 가용 재확인              ← STEP-24
   ├─ 가능 → 자동 확정(Reserve·결제)  /  해피콜 요청 건 = 전화 후 진행
   └─ 불가 → 날짜 변경 유도 or 취소 → 즉시·명확히 안내
        │
        ▼
중간 확정 안내 문자 단체 발송 ('침묵 구간' 불안 차단)          ← STEP-25
        │
        ▼
여권정보 미입력자 추출 → 입력 독촉 문자 (목표: 미입력자 0)      ← STEP-26
        │
        ▼
PNR(APIS) 생성 → 항공사 공유 → 시트 기록(△)                   ← STEP-27
   (에어마카오 = APIS 시스템 / 에어부산 = 전용 시스템 직접 입력)
        │
        ▼
항공권번호(에어마카오)·E티켓(에어부산) + 호텔 예약번호 매칭
   → 최종 확정 안내 문자 개별 발송 → ○ 체크                    ← STEP-28
        │
        ├─→ 여행자보험 가입 (트래블로버 B2B)                  ← STEP-29
        └─→ 세미·특수패키지 = 출국 D-3~5 QR 티켓 발권          ← STEP-30
        │
        ▼
   전 고객 발송·처리 완료 확인 → 🎉 공구 1사이클 완료
```

> ※ **진행상황 상시 공유**: 이 PHASE 전 구간 내내 인플에게 완료율 등 진행상황을 [[세일즈방|세일즈방]]으로 상시 공유한다(CS 대응도 그 흐름의 일부).

## 3. 핵심 포인트 / 참고

### 👤 담당
- 메인: 김용성 / 정민님(사수)
- 모를 땐 정민님 확인 후 답변(혼자 판단 금지). 변경·취소·환불은 임의 처리 금지 → 사내 확정 정책·환불 절차 준수.
- 물량 추가: 갤럭시(안다즈/브로드웨이) = **갤럭시 담당자님**께 요청 / 리스보아 = **리스보아 담당 이사님**께 확인.

### ① CS 응대 기본 원칙 (STEP-23)
- ⚠️ **응대 실수 → 고객 불만 → 인플루언서에게 전달 → 관계 단절**로 직결. 인플 질문은 우선순위 최상.
- 해피콜 등 전화 업무는 **통화녹음 필수**. 반복 문의는 [[CS 대응 문자 ( 패턴 )|CS 대응 문자 패턴]]으로 누적.
- 빠른 찾기:
  - 결항 안내 → [[결항 고객 안내 멘트 정리|결항 고객 안내 멘트]] (유류세 이슈 등)
  - No Show → [[항공편 No Show 경우|항공편 No Show]] (에어마카오: 출발편 미탑승 시 귀국편 비활성화)
  - 확정 후 취소 → [[예약 확정 이후 취소 방법|예약 확정 이후 취소 방법]]
  - 부분환불 → [[부분환불|부분환불]]
  - 추가결제(인펀트 등) → [[추가결제 링크 생성|추가결제 링크 생성]] ([[JBS|JBS]] '예트X추가결제' 탭, 인펀트 보통 16만원)
- **취소 수수료(질병·질환)**: 에어마카오 & 갤럭시엔터 = NO 패널티 / 에어부산 = 당사자+1인 NO 패널티, 나머지 인원 **인당 11만원**.

### ② 72시간 규칙 & 확정 채널 (STEP-24)
- 구매 후 **+72시간** 경과 건만 확정 진행 — 72시간 이전 확정 시 취소 수수료 발생 가능.
- 분기: [[해피콜|해피콜]] 메모에 요청('예약 확정 전 꼭 전화 주세요') 있는 건 = 전화 후 진행, 그 외 = [[자동확정|자동 확정]].
- 가용 확인 채널이 **항공사마다 다름**(혼동 주의): 에어마카오 = 모객현황 스프레드 좌석 / 에어부산 = 단톡방 요청.
- 호텔 부킹: shijicloud([[SCM|SCM]]) New Booking → Room Availability → 조식 포함/미포함 구분 필수 → Reserve.
- 결제 카드(MA 등) 정보는 본문 금지 → 사내 보안노트(자격증명은 담당자에게 요청). 객실 금액(MOP)과 공구 시트 금액 일치 확인 후 결제. 고객 국적 KR 변경.
- 호텔 투숙 규정(안다즈: 성인3 = Extra Bed 자동, 시스템 성인3 입력 불가 → 성인2+소인1 / 브로드웨이: 성인2+소인1 = MAX) → 상세 [[STEP-24|STEP-24]] 참조.
- ⚠️ [[SCM|SCM]] 확인 없이 확정 금지 → 오버부킹 시 전액 보상 책임.

### ③ 예약 확정 문자 = '2종' 구분 (STEP-25 / STEP-28)
- 고객 "예약 확정 언제 되냐" 문의 시 항상 2종으로 안내(원본: [[예약 확정 문자 대응|예약 확정 문자 대응]]).
  1. **예약 확정 전 안내 문자([[중간확정|중간확정]])** — 예약 넣기 전, 요청 건에 동의 여부 확인.
  2. **최종 예약 확정 안내 문자** — 확정 완료 후 출국일 1주일 전, 항공권번호·호텔 예약번호 포함.
- 요청 사항('확정 후 꼭 연락') 없으면 자동 확정 진행(따로 연락 안 함).
- ⚠️ **미확정 고객에게 확정 문자 발송 금지** — 명단 확정/미확정 명확히 구분.

### ④ 여권정보 수집 폼 (STEP-26)
- 공구별 **신규** 구글폼 사용([[구글폼|구글폼]]). 직전 공구 폼이면 [[STEP-17|STEP-17]]에서 교체했는지 먼저 확인(이전 폼 수집 시 대형 CS).
  - 마카오 일반: [내부 링크 삭제]
  - 마카오 리스보아: [내부 링크 삭제]
- 여권 영문 철자·생년월일 **오타 = 발권 오류**. 미수집·공백 칸은 자의적 추정 금지 → 전화 직접 확인. 목표: 여권 미입력자 0.

### ⑤ PNR(APIS) 생성 — 채널별 차이 (STEP-27)
- **여권·여정 확정 건만** 추출(미확정·미수신 섞지 말 것 → [[STEP-26|STEP-26]]로 재수집).
- 에어마카오: APIS 시스템에서 생성. 여권 없을 때 임시번호 **`m0000000`** / 인펀트 포함 시 해당 승객 수에서 **INF로 수정 후 저장**([[인펀트 APIS|인펀트 APIS]]).
- 에어부산: 전용 시스템 직접 입력(영문 성/이름·생년월일·성별·여권번호·만료일).
- 생성 후 시트에 PNR 입력 + **세모(△)** 표시 → 항공사 공유. ⚠️ **오기입 = 변경 수수료·전액 패널티 → 무조건 더블체크**(동료 교차 확인).
- 영문명 변경 양식(발권 후 오류 시) → [[여권 영문명 변경 (에어마카오)|여권 영문명 변경 (에어마카오)]], 채널은 [[에어마카오 담당자 문의|에어마카오 담당자 문의]].

### ⑥ 최종 확정 = 매칭 오류가 곧 현장 사고 (STEP-28)
- 발급 형태 혼동 금지: **에어마카오 = 항공권 번호(13자리)** / **에어부산 = E티켓(PDF)**.
- 고객 ↔ 항공 ↔ 호텔 예약번호를 시트에 매칭 입력 후 이름·여정·인원 **육안 재확인**. 다른 고객 번호 발송 시 현장 탑승/체크인 사고.
- 출국일 1주일 전 개별 발송 → 발송 후 **동그라미(○)** 체크. **한 건이라도 미발송이면 공구 종료 처리 금지.**

### ⑦ 여행자보험 (STEP-29)
- 단체문자로 본인 포함 동행자 전원 주민번호(뒷자리 포함) 수집([[단체문자 (여행자보험) 멘트|단체문자 (여행자보험) 멘트]]). **민증 뒷자리 공백 = 자의 처리 금지, 전화 확인.**
- 트래블로버 B2B([내부 시스템 주소 삭제]): 담당자 김민경 / 이메일 `ot@yestravel.co.kr` / 단기해외여행·마카오 / 맨 왼쪽 오렌지색 상품 / 가상계좌(기업은행) / 사업자번호 315-87-02973. 완료 시 보험 스프레드 노란색 색칠.
- ⚠️ 보험 실수 = 사고 시 보상 불가·법적 분쟁. 상세 [[여행자 보험 가입 방법|여행자 보험 가입 방법]].

### ⑧ QR 티켓 발권 (STEP-30)
- **세미·특수패키지 고객만** 대상(일반 [[에어텔|에어텔]] 제외), 출국일 **3~5일 전** 발권.
- [[클룩 에이전트 정보|클룩 에이전트]]에서 발권(로그인 PW는 사내 보안노트(자격증명은 담당자에게 요청)) → 문자/카카오 전달.
- ⚠️ **[[세미패키지|세미패키지]] 일정 구성 규칙**: 패키지는 무조건 **출발날짜 다음날(2일차)**에 들어가야 함 → 잘못될 시 **금액적 패널티 발생**. (출처: 기존 백업 '05 마감 & 확정 처리' §4 — 발권·일정 구성 시 반드시 확인.)
