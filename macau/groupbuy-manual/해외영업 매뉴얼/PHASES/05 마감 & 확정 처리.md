## 1. 전체 흐름
```
공구 종료
    ↓
결제 최종 확인
    ↓
항공·호텔 확정 (불가능 시 날짜 변경 유도 or 취소)
    ↓
PNR(항공 예약번호) 생성 ← 반드시 더블체크
    ↓
여행자보험 가입 정리
    ↓
패키지 정리 (출발 날짜 다음날 2일차 기준)
    ↓
엑스트라베드 메일 요청 (템플릿 사용)
    ↓
고객 확정 문자 발송 → 동그라미 체크 → 해당 공구건 마무리
    ↓
[[06 매출 보고|→ 매출 보고로]]
```

## 2. PNR(항공 예약번호) 생성
#PNR #발권 #APIS #에어마카오 #더블체크

> ⚠️ **잘못 기입 시 금액적 패널티 발생 → 무조건 더블체크**

### APIS 생성 방법
> 상세: [[마카오 업무 흐름 정리#에어마카오 APIS(PNR) 생성 방법|▶ 에어마카오 APIS 생성 방법]]

| 상황 | 처리 방법 |
|------|----------|
| 여권 정보 없을 때 | 임시번호 `m0000000` 입력 |
| 유아(Infant) 포함 시 | 해당 승객 숫자에서 INF로 수정 후 저장 |
| 여권 영문명 변경 필요 | [[여권 영문명 변경 (에어마카오)\|🛂 여권 영문명 변경]] |
