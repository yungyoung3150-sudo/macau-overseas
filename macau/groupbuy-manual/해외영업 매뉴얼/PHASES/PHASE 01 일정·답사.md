# 🎯 PHASE 01 일정·답사
#일정 #답사 #캘린더 #스크럼 #시딩

> 공구의 출발점. 대표님이 인플([[KOL|KOL]])을 섭외해 시딩 일정을 잡으면, 그 일정을 받아 **캘린더에 등록**하고 매일 아침 **스크럼 전 캘린더를 확인**해 다가오는 답사·시딩을 놓치지 않는 단계다.

## 3. 핵심 포인트 / 참고

### 인플 매칭은 피드부터 본다 (기존 디테일 이식)
> ⚠️ **핵심 원칙:** 인플의 인스타 피드를 직접 확인해서 현재 어떤 콘텐츠를 올리는지, 팔로워 반응은 어떤지 파악 후 상품을 매칭한다. 안 갔다가 온 걸 주면 홍보가 안 된다.

| 체크 항목 | 확인 방법 |
|-----------|----------|
| 최근 마카오 홍보 여부 | 인스타 피드 직접 확인 |
| 팔로워 반응 (좋아요·댓글) | 게시물 반응 확인 |
| 가족형 / 무자녀 / 커플 | 피드 콘텐츠 유형 파악 |
| 지방 출발 고객 비중 | 댓글·DM 확인 |

> 📌 팔로워 수·판매력 관계없이 일단 최대한 다 맞춰준다.
> 📌 인플마다 [[세미패키지|세미패키지]] 진행 여부가 다르니 반드시 확인.

### 일정·답사 확정 시 챙길 정보
대표님이 준 시딩 일정을 받으면, 다음 단계([[PHASE 02 시딩(촬영) 지원|시딩 지원]])에서 에어마카오·갤럭시·리스보아에 전달할 정보를 미리 정리해 둔다.
- [ ] 일정 확정 여부 (출국·귀국일)
- [ ] 인원 수
- [ ] 인플루언서 정보 (채널 링크, 팔로워 수)
- [ ] 숙박 기간
- [ ] (다음 단계용) 항공편 [[바우처|바우처]] / 호텔 [[바우처|바우처]] 준비 여부

### 캘린더 등록 & 아침 스크럼
- 확정된 답사·시딩 일정은 **캘린더에 바로 등록**한다.
- 매일 아침 **스크럼 전 캘린더를 확인**해 임박한 답사·시딩·출국 일정을 점검한다.
- ⚙️ 보완(확인필요): 사용하는 캘린더 종류·공유 범위, 스크럼 시각 등 구체값은 백업에 명시되어 있지 않음 — 운영하며 채워 넣을 것.

### 인플루언서 등급 (참고)
| 등급 | 팔로워 규모 |
|------|------------|
| Mega | 100만+ |
| — | 60만 / 50만 / 30만 / 20만 |
