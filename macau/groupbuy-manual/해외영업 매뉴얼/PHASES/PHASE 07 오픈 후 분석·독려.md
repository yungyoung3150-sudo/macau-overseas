# 📈 PHASE 07 오픈 후 분석·독려
#매출보고 #판매분석 #세일즈방 #클라이언트 #인플독려 #에어마카오단톡 #갤럭시 #리스보아

## 1. 전체 흐름
```
오픈 후 1차 매출 보고(STEP-21, PHASE 06)
    ↓
오픈 다음날(D+1) 판매 상황 집계 — 시트 통계 부분 확인
    ↓
같은 데이터 → 받는 쪽 따라 3종으로 분리해 공유
    ├─ ① 세일즈방(카톡방)   : 판매 상황 요약
    ├─ ② 클라이언트          : 판매 공유 + "왜 팔렸나/왜 안 팔렸나" 원인 분석 + 개선안
    └─ ③ 인플                : 매출/성과 공유 + 추가 홍보 독려
    ↓
(채널별 매출 보고) 에어마카오 단톡방 · 갤럭시 담당자님방 · 리스보아 단톡방
— 정민님이 올린 것 확인 후 보고
    ↓
오픈 후 1주일간 매일 — 취소 사유별 퍼센테이지 · 취소 금액 트래킹
```

## 2. 포함 STEP
- [[STEP-22|STEP-22]] 오픈 다음날 판매 분석 3종 공유 — 이후 1주일간 취소 사유·금액 추적

> 오픈 당일 1차 매출 집계·대표 보고는 직전 [[STEP-21|STEP-21]](소속 [[PHASE 06 오픈 D-3~D데이|PHASE 06]])에서 끝낸다. 이 PHASE는 그다음 날(D+1) **분석·독려** 단계다.

## 3. 핵심 포인트 / 참고

### 3-1. 3종 공유 — 받는 쪽이 다르면 형태를 분리한다
오픈 다음날, 같은 판매 데이터라도 받는 쪽이 다르므로 톤과 내용을 나눠 공유한다.

| 공유 대상 | 채널 | 담는 내용 |
|----------|------|----------|
| ① [[세일즈방]] | 카톡방 | 전날 판매 상황 요약(매출·건수 등 기본 지표) |
| ② [[클라이언트]] | — | 판매 상황 공유 + **"왜 팔렸나 / 왜 안 팔렸나"** 원인 분석 + 개선안 |
| ③ [[KOL|인플]] | — | 인플 관련 매출/성과 공유 + 추가 홍보 제안으로 독려 |

> 📌 클라이언트·인플 공유는 **파트너 존중 톤**과 **팩트 등급**이 필수. 검증되지 않은 내용을 단정형으로 쓰지 말고, "해외 미개척/0건" 같은 단정도 금지한다.

### 3-2. 채널별 매출 보고 (기존 흐름 유지)
호텔·항공사 매출 보고는 각 단톡방에서 **정민님이 올린 것을 확인한 뒤** 보고한다.

| 보고 대상 | 채널 | 방법 |
|----------|------|------|
| 에어마카오 | 에어마카오 단톡방 | 정민님이 올린 것 확인 후 보고 |
| 갤럭시 | 갤럭시 담당자님방 | 정민님이 올린 것 확인 후 보고 |
| 리스보아 | 리스보아 단톡방 | 정민님이 올린 것 확인 후 보고 |

> 📌 **시트 통계 부분**을 확인해서 수치를 입력한다.

### 3-3. 오픈 후 1주일 취소 트래킹 (기존 흐름 유지)
오픈 다음날 3종 공유로 끝이 아니다. **오픈 후 1주일 동안 매일** 취소를 추적한다.

- 취소 **사유별 퍼센테이지**
- 취소 **금액** 정리

> 📌 취소 패턴 파악이 다음 [[앵콜딜|앵콜딜]] 개선에 직결되므로 1주일 일간 추적은 필수다. 상세 절차는 [[STEP-22|STEP-22]] 참고.

### ⚙️ 보완(확인필요)
- 3종 공유에 들어가는 분석 지표 항목(예: 매출·건수·상품별 비중 등)과 클라이언트용 원인 분석 양식 — 사내 기준 확인 후 보완.
- 집계 기준 데이터 소스(어느 화면·시트에서 매출/건수를 읽는지), 인플 공유 채널·문구 — 확정 후 보완.
