## 1. 전체 흐름
```
최저가 모니터링 (항공 + 호텔)
    ↓
때에 따라 최신 정보 업데이트 필요하면 완료까지 딜레이 가능
    ↓
모니터링 끝나고 본부장님한테 슛 (차액 계산기 구글 시트)
    ↓
본부장님이 공헌이익 계산 후 요금표 제작 및 전달
    ↓
[[03 판매 페이지 세팅|→ 상점 세팅으로]]
```

## 4. 요금표 제작 → 본부장님 전달
#요금표 #차액계산기 #공헌이익

### 프로세스
1. 모니터링 완료 → 차액 계산기 구글 시트에 정리
2. 본부장님한테 슛
3. 본부장님 공헌이익 계산 완료 → 요금표 수령
4. 요금표 기반으로 [[03 판매 페이지 세팅]] 진행
