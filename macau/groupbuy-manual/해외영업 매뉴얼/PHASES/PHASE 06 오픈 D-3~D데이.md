## 1. 전체 흐름
```
[D-3 ~ D-day] 인플 홍보 피드 점검 (STEP-18)
   ↳ 가격·일정·판매링크를 셋팅 확정값과 글자단위 대조
    ↓
피드 반응 모니터링 → 트래픽 예측 → 서버 증축 선요청 (STEP-19)
   ↳ "요청"과 "적용 확인"은 별개 — 오픈 전 적용 완료 확보
    ↓
[D-day] 공구 오픈 확인 (히든 해제) & 판매링크 노출 (STEP-20)
   ↳ 상점 공개·판매코드·여권 수집 폼 실클릭 점검 (1순위)
    ↓
오픈 직후 1차 매출 집계 → 세일즈방 보고 → 인플 성과 공유 (STEP-21)
    ↓

    ↓

```

## 3. 핵심 포인트 / 참고
#실시간CS #색상규칙 #인플소통

### 오픈 직전·직후 1순위 점검 (STEP-18·20)
- 인플 피드의 가격·일정·판매링크를 [[상세페이지|상세페이지]]·[[판매코드|판매코드]] 확정값과 **글자 단위로 대조**. [[후킹가|후킹가]]·[[소구포인트|소구포인트]]가 셋팅과 어긋나면 [[KOL|KOL]]에게 D-day 전 수정 요청.
- 오픈 시각에 [[상점|상점]] 공개([[히든|히든]] 해제) 여부, [[JBS|JBS]]·Janda 판매 페이지 **실클릭** 정상 작동, 인플 채널 판매링크 노출을 직접 확인.
- ⚠️ **여권 수집 [[구글폼|구글폼]]은 반드시 이번 공구용 신규 링크인지 확인** — 이전 공구 폼으로 수집되면 대형 CS로 직결.

### 서버 증축은 "선요청 + 적용 확인" (STEP-19)
- 피드 반응(좋아요·댓글·문의)으로 오픈 트래픽을 예측. 댓글은 **구매 대기열 신호**로 읽는다.
- 평소 [[공구|공구]] 대비 반응이 크면 **오픈 전에 미리** [[서버 증축|서버 증축]] 요청. 오픈 직후 대응은 이미 늦다.
- 요청 접수 ≠ 적용 완료. 오픈 전 적용 완료까지 직접 확인.
- ⚙️ 보완(확인필요): [[서버 증축|서버 증축]] 요청처·승인 라인·리드타임, "트래픽이 크다"의 판단 임계치는 사내 미확정.

### 패키지 시트 색상 규칙 (오픈 직후 운영)
> 📌 **파란색** = 금일 결제 진행 건 **OR** 결제 완료 후 안내 메시지를 보내야 하는 팀

| 색상 | 의미 |
|------|------|
| 파란색 | 당일 결제 건 / 확정 문자 발송 필요 |
| (기타 색상) | 추가 확인 필요 |

### 실시간 CS 대응 — 오픈 직후 바로 전환
> ⚠️ **중요:** 고객 응대 실수 → 불만 → 인플루언서에게 이어짐 → 관계가 끊어질 수 있음. 오픈 직후 CS 급증에 대비해 [[CS 대응 문자 ( 패턴 )|CS 대응 문자 패턴]]을 미리 펼쳐두고 대기.
- [[CS 대응 문자 ( 패턴 )|CS 대응 문자 패턴]] — 자주 쓰는 답변
- [[고객 예약 확정 프로세스|고객 예약 확정 프로세스]]
- [[추가결제 링크 생성|추가결제 링크 생성]]
- 자주 오는 문의: 결제 방법 / 취소·환불 / [[인펀트|인펀트]](유아) 추가 비용 / 항공 관련 → 상세 대응은 [[PHASE 08 CS·예약 확정|PHASE 08]]

### 인플루언서 소통 유의 (STEP-18·21)
- 구성을 일부러 안 고르는 분이 있음(책임 전가 방지·밑밥) → 옵션을 **명확히 제시**.
- 오픈 후 인플 게시물 홍보 노출·반응을 지속 모니터링.
- 인플에 공유하는 성과 숫자는 **검증된 팩트만**, 파트너 존중 톤 유지(과장·추정 단정 금지). ([[KOL|KOL]] 응대 원칙)

### 오픈 후 1차 매출 보고 (STEP-21)
- 오픈 직후 매출·건수 집계 → [[세일즈방|세일즈방]] 1차 공유(대표/팀) → 각 [[클라이언트|클라이언트]] 단톡방(에어마카오·갤럭시·리스보아) 보고.
- ⚠️ 클라이언트 단톡방 보고는 **정민님이 올린 것 확인 후** 진행(중복·상충 방지).
- 본격 분석(3종 공유 + 1주일 취소 트래킹)은 [[PHASE 07 오픈 후 분석·독려|PHASE 07]]로 이어짐.
