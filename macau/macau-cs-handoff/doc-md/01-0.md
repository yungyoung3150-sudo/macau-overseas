### 항공 결항이면 호텔은 어떻게 취소되나요?

흐름: 결항 → 고객 취소 요청 → 호텔별(안다즈·브로드웨이 예약팀 각각) 영문 메일 + 항공사 결항 공문 첨부 → 호텔이 취소 가능 여부 회신 → 받아들여지면 고객 취소 처리.  
우리 계약은 「예약 확정 후 Non-cancellation」이라 메일은 면제 「요구」가 아니라 「취소 가능 여부 확인 요청」이다.  
취소 대상 판별 = 「마카오 결항건」 시트(월별 탭): 하늘색 = 변경 요청 → 이미 변경 완료(취소 아님) / 빨간 글씨 = 취소. 비고의 「이름 = NX821-NX822」류는 제안한 대체편이지 원 여정이 아니다.  
호텔 말고 「마카오 버스투어」 시트도 확인: 마카오타워 입장권 + 런치뷔페 + 야간버스투어가 별도 예약으로 잡혀 있어 같이 취소·환불해야 고객 돈이 남지 않는다.

**주의.** 호텔 회신 전 고객에게 취소·환불 확답 금지. 결항 시 추가 숙박비·차액 지원 없음, 무상은 「취소」뿐이며 고객이 먼저 물을 때만 언급. 체크인 당일 건은 노쇼 방지를 우선 요청. 결항·대체편 정보는 시트19가 최우선.

**고객 답변 예시.**

> 결항으로 인한 호텔 취소는 저희가 호텔에 요청을 접수했으며, 호텔 회신을 받는 대로 결과를 안내드리겠습니다.

### 결항되면 대체편은 어떤 비행기로 바뀌나요?

- 인천 출발: NX825(오전) ↔ NX821(오후)  
- 마카오 출발: NX822(오전) ↔ NX826(저녁)

### 결항 때문에 날짜를 바꾸거나 1박 연장하면 추가 숙박비를 지원해 주나요?

**주의.** 「최대한 방법을 찾아드리겠습니다」「부담하실 금액은 없습니다(무조건형)」「항공권과 호텔 모두 저희가 정리해 드립니다」 금지 — 회사가 추가 비용을 낸다는 뜻으로 읽힌다. 묻지 않은 고객에게 비용 경계를 먼저 쓰지 않는다.

> 다만 추가 숙박에 대한 비용은 저희가 지원해 드리기 어려운 부분이라, 확인되는 금액을 먼저 안내드리겠습니다.

### 상세페이지에 「예외 항공 스케줄」이 적혀 있던 상품은 결항이면 어떻게 하나요?

상세페이지에 결항 날짜의 「예외 항공 스케줄」이 안내된 뒤에 구매한 고객은 결항 안내 대상이 아니라, 처음부터 예외편으로 판 건(대기상품)입니다. 이 고객에게는 「예외 항공 스케줄로 진행 동의」 회신을 받고, 결항 시트 P열 「예외편 판매」·Q열 체크로 관리합니다.  
상세페이지 예외 스케줄 안내가 올라가기 전에 산 고객은 일반 결항 고객처럼 결항 안내를 보냅니다.  
대기상품이라도 상세 예외 스케줄 이미지에 그 결항일이 적혀 있지 않으면 결항 시트에 추가해 결항 안내 대상으로 봅니다.
