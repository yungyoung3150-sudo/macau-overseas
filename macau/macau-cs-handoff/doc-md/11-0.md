### 고객 한 명의 호텔 예약번호·룸타입·투숙일은 어디서 찾나요?

- 호텔 예약번호·룸타입·체크인/아웃의 원천 = 개별 공구 시트(「YYYYMMDD 인플 X 마카오」)의 「예약리스트」 탭. 출국일=체크인, 입국일=체크아웃.  
- 통합 원장 = 「마카오 해피콜_No해피콜(응답)」 시트(공구 구분 없이 전부, 예약자명·연락처·출발일·호텔·인원·여권). 단 호텔 예약번호와 공구명 칸이 없어 딜 특정은 공구 시트로만.  
- 취소 여부 = 「결제 취소 요청」 시트 대조.  
- 호텔 예약번호 자릿수: 안다즈 7자리(23xxxxx·24xxxxx) / 브로드웨이 8자리(142xxxxx·143xxxxx). 한 주문에 2객실이면 예약코드는 같고 호텔 예약번호만 다르다.  
- 여권 정보는 「여권정보」 탭이 아니라 「폼 입력」 탭(또는 공구별 여권 폼 응답 시트)이 정본.

**주의.** 이름만으로 대조 금지 — 동명이인이 있어 반드시 연락처로 확인(앞자리 0이 빠진 10자리로 저장된 시트도 있음). 「여권정보」 탭은 열이 밀린 행이 많고 전 공구 공유 블록이라 딜 특정 불가. 「에어마카오 예약용」 탭의 룸타입은 템플릿 잔값. 「취소」 탭은 평소 볼 필요 없음(행이 밀려 있음). 회사 시트는 읽기만.

### 공구 시트 상태 칸 「O / △ / X」는 무슨 뜻인가요?

상태 칸이 두 개입니다.  
A열 = 항공권 상태(O / △ / X / 여권정보 미비 / 신규APIS / 결항 미정). 매뉴얼 기준 △ = PNR 생성·항공사 공유, ○ = 최종 확정 안내 발송 완료. X는 「발권할 때 한 번 더 확인」 표시이지 취소·불가 뜻이 아닙니다.  
Y열(헤더 「-」, 우주맘마는 U열) = 진행 상태(완료·해피콜완료·취소·여권 미입력 등). 리스보아 딜(다온맘)은 X열 「여권정보미입력」처럼 시트마다 칸·값이 다릅니다.  
「취소유무」 열은 수식이라, 옛 주문코드가 남은 재예약 행은 확정이어도 1(취소)로 뜰 수 있습니다.

**주의.** X를 보고 고객에게 「취소됐다」고 하면 안 됩니다. 상태 값은 직접 바꾸지 말고 용성에게 요청하세요.
