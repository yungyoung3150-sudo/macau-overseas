### 항공권 영문 이름이 틀렸어요. 고칠 수 있나요?

영문명은 고객이 에어마카오 사이트에서 직접 고칠 수 없습니다. 저희 채팅상담으로 변경 신청을 받아 저희가 처리합니다.  
출국 당일에는 변경이 안 되므로 미리 알려 달라고 안내합니다.  
접수 후 실제 정정 처리는 발권 담당(용성)에게 넘깁니다.

**주의.** 정정 완료를 확인하기 전에 「바로 수정됐습니다」라고 답하지 않는다. 처리 시간·가능 여부는 용성 확인 후 안내.

**고객 답변 예시.**

> 영문 성함 정정은 저희 쪽에서 변경 신청을 도와드리고 있습니다. 출국 당일에는 변경이 어려우니 여권과 동일한 영문 성함을 이 채팅으로 미리 남겨 주세요.

### 확정 안내에 여권번호가 「-」로 나오거나, 여권번호·만료일이 틀렸어요

확정 안내의 생년월일·성별·여권번호·여권만료일은 에어마카오 발권 기록 값 그대로 보여 줍니다(우리 여권 폼 값으로 덮지 않음). 고객이 자기 항공권 여권정보를 대조하라고 보내는 것입니다.  
- 여권번호·만료일이 「-」 = 발권 때 여권 미입력(임시값 M00000000 / 01JAN31로 발권). 「여권 정보 확인 필요 승객」 안내 + 체크인 가이드 PDF가 같이 나갑니다.  
- 여권번호·만료일 오류는 발권을 막지 않고, 고객이 에어마카오 사이트(온라인 체크인)에서 나중에 직접 수정할 수 있습니다.  
- 이름·생년월일·성별 오류는 고객이 못 고치므로 저희에게 접수 → 용성에게 전달합니다.

### 여권정보를 잘못 입력했다고 하면?

발권 전이면 여권 폼을 다시 제출하게 합니다. 맨 아래(가장 최근) 제출 값이 통째로 쓰입니다.  
발권에 박히는 항목(영문 이름·생년월일·성별)은 중요합니다. 발권 후 영문명이 틀렸으면 항공권번호와 함께 에어마카오에 영문명 변경 요청이 필요하니 용성에게 넘깁니다.  
여권번호·여권 만료일 오류는 발권을 막지 않습니다. 나중에 에어마카오 사이트에서 바꿀 수 있습니다(2026-10-22).  
확정 안내문의 여권정보는 항공사 발권 기록 값을 그대로 보여 줍니다. 고객이 자기 항공권 기록이 맞는지 대조하라고 보내는 것이라, 우리 폼 값으로 덮지 않습니다.

**주의.** 여권번호·만료일 수정 방법을 고객에게 어떻게 안내할지(사이트 직접 수정 안내 문구)는 노트에 고객용 표준 문구가 없어 용성 확인 필요. 이름·생년월일 오류는 반드시 용성에게.

**고객 답변 예시.**

> 수정이 필요하신 경우 여권정보 입력 폼으로 다시 한 번 제출해 주시면, 가장 최근에 제출하신 정보로 확인해 안내드리겠습니다.

### 여행자 보험이 포함돼 있나요?

공구마다 다릅니다. 마카오는 대부분 보험 미포함입니다. 예외(포함): 윤아 X 마카오 야간버스, 제니 X 마카오 11월~ 앵콜, 로로 X 마카오(용성이 따로 포함). 공구 시트 예약리스트의 「여행자보험」 체크칸이 체크돼 있으면 포함 공구입니다.  
보험사는 인슈가드이고, 신청 엑셀을 보내고 가입증명서 PDF를 회신받습니다. 신청은 용성이 합니다.  
여권정보 미입력 팀은 가입이 안 돼서 보험 리스트에서 빠지고, 공구 시트 비고에 「여행자 보험가입 안됨」이 적힙니다.  
보험 가입용 주민번호는 생년월일·성별로 만듭니다(앞 6자리 + 뒷자리 첫 숫자).

**바뀐 점.** 매뉴얼(2026-06)은 트래블로버 B2B 가입 → 2026-10-30 기준 인슈가드로 신청.

**주의.** 포함 여부는 꼭 고객이 산 공구 기준으로 확인하세요. 매뉴얼의 「주민번호 뒷자리까지 답장으로 받는」 옛 단체문자 방식은 지금 쓰지 않는 것으로 보이니(현재는 여권 생년월일로 생성) 고객에게 주민번호를 요구하기 전에 용성 확인 필요.
