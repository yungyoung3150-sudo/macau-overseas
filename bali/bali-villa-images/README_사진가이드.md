## ⚠️ 사진/사실 확인 필요 (검증 결과)

- **울루벨리(빌라3)** — "울루벨리"라는 이름이 특정 리조트로 **확정 확인되지 않음**. 기능(어덜트온리·밸리 스윗룸·정글 풀빌라·120분 마사지·로맨틱 디너)은 우붓 정글빌라(예: The Kayon Jungle/Valley Resort)와 유사하나, 이름이 우붓이 아닌 **울루와뚜(Uluwatu)**를 가리켜 일치하지 않음. **본부에 정확한 빌라명을 확인한 뒤** 위치·시그니처·사진을 확정하세요. (현재 상세페이지는 노션에 적힌 사실만 기재, 위치·시그니처는 주장하지 않음)
- **로얄산트리안** — 공식 기준 빌라 총 20채(디럭스 17 + 로얄 3). '22채' 등 일부 OTA 수치는 부정확.
- **더엣지** — oneeighty° 스카이풀 "해수면 위 약 162m·절벽 너머 약 6.5m"는 **호텔 자체 표기 수치**.
- **클레오 스미냑** — 2025.7.20 오픈 신상, 동남아 첫 JdV by Hyatt. '5성급' 표기는 미확인이라 상세페이지에 쓰지 않음(부티크 라이프스타일 호텔로 표기).
- **지바** — 스미냑 페티텡엣의 부티크 풀빌라(Ziva). **롬복의 Jeeva 리조트와 다른 곳**이니 혼동 주의.
